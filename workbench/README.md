# workbench — 板块四·前端工作台

接入信息源的可视化工作台：资讯聚合（标签筛选）→ 图文/视频制作（产物回显）→ 账号追踪 → 设置。
**本期为展示/UI 壳**：资讯页与设置页接真实数据，生成/发布/云同步全部留桩。
方案定稿见 [docs/第四板块-前端工作台方案.md](../docs/第四板块-前端工作台方案.md)（MoA 四岗方案存档在 `docs/workbench-moa/`）。

## 快速开始

```bash
# 终端 A: 起数据站(板块一, 资讯页的数据来源)
python cli.py sources serve          # 127.0.0.1:8787

# 终端 B: 起工作台
python cli.py workbench serve --open # 127.0.0.1:8788, 自动开浏览器
```

无 Node、无构建、无 CDN——clone 即用（fastapi+uvicorn 与板块一同一份依赖）。

## 五个页面

| 页面 | 路由 | 本期状态 |
|---|---|---|
| 资讯 | `#/news` | ✅ 全功能：标签筛选(市场/类型/信息类别/情绪/渠道/形态/来源) + 搜索 + 时效 + 游标翻页 + 同事件折叠 + 中英切换 + 素材篮 |
| 图文 | `#/article` | 素材篮 + 工作流状态机回显 + 产物/队列只读浏览；生成/发布按钮为桩 |
| 视频 | `#/video` | 项目列表(draft→reviewed→built 门禁徽章) + mp4 播放；构建/投稿为桩 |
| 追踪 | `#/track` | 追踪账号真实增删(落盘) + 已发布清单(账本只读)；粉丝/流量采集留桩 |
| 设置 | `#/settings` | ✅ 信息源连接(模式/地址/Key/测试连接) 真实可用；界面偏好；环境自检；云端同步 501 预留 |

## 依赖矩阵

- **数据**依赖板块一：`sources serve` 供数（经 `/wb-api/v1/*` 代理，前端不直连 8787，Key 不出服务端）。
- **动作**依赖板块二/三：本期全部留桩；未来也只经 `subprocess 调 python cli.py ...`，不 import 内部模块。

## 运行时数据（gitignored）

| 文件 | 语义 |
|---|---|
| `data/workbench/settings.json` | 工作台设置（数据源/界面/云端预留），设置页唯一写口 |
| `data/workbench/tracked_accounts.json` | 追踪账号清单 |

## 红线

- 三板块文件（state.json/run.json/产物目录）**全程只读**；唯一写口是 `data/workbench/` 自有 JSON。
- 默认绑 127.0.0.1；`--bind 0.0.0.0` 对外时与 sources serve 同一告诫：内网/隧道，禁裸公网。
- 发布永远 `--draft` 先行（本期发布按钮全是桩，未来实装时真发必须前端二次确认）。
