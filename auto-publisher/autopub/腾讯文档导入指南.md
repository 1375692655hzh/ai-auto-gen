# 腾讯文档导入 · 使用指南

把腾讯文档链接变成待发文章：**图文完整导出**为 docx 进 `articles/` 队列，
后续发布流程（选平台 → 发布）与其他文章完全一致。

本项目**已内置**腾讯文档对接（`tdoc_client.py`，纯 Python，无需安装任何
外部 skill / mcporter / npm 包）。你只需要做一次扫码授权。

---

## 一、一次性授权（约 1 分钟）

> Token 授权一次长期有效，存在本机 `secret.local.json`（不会随项目分享出去）。

### 方式 A · 控制台里点按钮（推荐）

1. 启动控制台：`py webapp\app.py` → 打开 `http://127.0.0.1:5001`
2. STEP 2 上传区会显示腾讯文档授权状态；点 **「去授权」**
3. 浏览器自动打开腾讯文档授权页 → **用 QQ 或微信扫码**确认
4. 控制台自动检测到授权完成（约 3 秒内状态变 ✅）

### 方式 B · 命令行

```cmd
cd auto-publisher\autopub
py tdoc_client.py auth
```

同样扫码即可；`py tdoc_client.py status` 可随时检查授权是否有效。

---

## 二、日常使用

控制台 STEP 2 的输入框粘贴文档链接（形如
`https://docs.qq.com/doc/DXXXXXXXX`）→ 点 **「导入」** → 约 10~30 秒后
文章（docx）出现在待发列表，标题 = 文档标题。

- **图文全保真**：文档里的图片、加粗、标题层级随 docx 原样保留，
  发布到各平台时照常上传图片。
- **文档权限要求**：只要你授权的 QQ/微信账号能打开这个文档即可
  （自己账号创建的、或分享给你的都行；不要求"任何人可查看"）。
- **支持类型**：Word 类在线文档（`docs.qq.com/doc/...`）。
  Excel/PPT/收集表暂不支持。

---

## 三、常见问题

| 现象 | 原因与处理 |
|---|---|
| 导入结果标注"纯文本(无图)" | 腾讯文档未授权，自动降级为纯文本模式。按上面步骤完成授权后重导 |
| 提示"Token 失效或无权限" | Token 过期：重新点「去授权」（或 `py tdoc_client.py auth`）扫一次码 |
| 提示 vip_required / 积分不足 | 腾讯文档侧的用量限制（导出是 VIP/积分能力），按提示页处理 |
| "仅支持 Word 类文档" | 链接是 Excel/PPT 等；导出仅支持 Word 类在线文档 |
| 命令行手动导入 | `py import_tencent_doc.py --url https://docs.qq.com/doc/DXXXX` |

> 兼容说明：如果机器上已配置过 mcporter（`tencent-docs` 服务），本项目会
> 优先使用内置直连通道，mcporter 作为后备，互不影响。
