# auto-publisher 使用指南（团队版）

一个**在你自己电脑上运行**的多平台自动发文工具：把写好的文章（Word/Markdown）一次发到老虎社区、东方财富股吧、雪球、知乎。

> 全程在本机运行，用你自己的浏览器登录态发文。**不上传你的账号密码到任何服务器**，也不要把本工具部署到公网。

---

## 一、第一次准备（约 10 分钟，只需一次）

### 1. 装环境

需要 **Python 3.9+** 和 **Google Chrome**。

**macOS / Linux：**

```bash
pip3 install flask playwright pyyaml python-docx requests
python3 -m playwright install chromium     # 装自动化用的浏览器内核
```

**Windows：** 命令里用 `py`（不是 `python3`）。先确认 Python 版本是 3.9+：

```cmd
py --version
py -m pip install flask playwright pyyaml python-docx requests
py -m playwright install chromium
```

> ⚠️ **Windows 常见坑**
> - 若 `py --version` 显示 **Python 2.x**（老 Anaconda 等）或提示找不到：去 [python.org](https://www.python.org/downloads/) 装 **Python 3.11/3.12**，安装时**务必勾选 `Add python.exe to PATH`**，装完重开 CMD，再用 `py` 跑上面的命令。
> - `py -m playwright install chromium` **卡住下不动**（国内网络）：先设国内镜像再下——
>   ```cmd
>   set PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright
>   py -m playwright install chromium
>   ```
>   （PowerShell 用 `$env:PLAYWRIGHT_DOWNLOAD_HOST="https://cdn.npmmirror.com/binaries/playwright"`）

> 工具默认用上面下载的 **Chromium 内核**（和 Chrome 同内核，无需另装浏览器）。本机有 Chrome/Edge 的，可在 `config.yaml` 里把 `browser.channel` 改为 `chrome` / `msedge` 直接复用。

### 2. 启动控制台

```bash
python3 webapp/app.py      # macOS / Linux
py webapp\app.py           # Windows
```

看到 `http://127.0.0.1:5001` 后，用浏览器打开它。后面所有操作都在这个网页里点。

## 二、网页四步走

### STEP 1 · 模型 API 设置（**可选**）

- **什么时候需要**：只有当你要发 **知乎 / 东方财富**，且文章里有「下图/下表/如图」这类依赖图片、但图片在该平台传不上去的情况——这时工具会调用模型，把图表的关键信息**转成一句文字**补进正文。
- **不发这两个平台、或文章没有这种图**：可以完全跳过这一步。
- **怎么填**：
  - `provider` 选你用的服务商（`deepseek` / `openai` / `qwen` 通义 / `moonshot` Kimi / `zhipu` 智谱 / `ollama` 本地，或自定义）
  - `model` 填模型名，例如 `deepseek-chat`、`gpt-4o-mini`、`qwen-plus`
  - `base_url` 一般留空（按服务商自动带默认）；用中转/自建才填完整地址
  - `API Key` 粘贴你自己的密钥
  - 点 **保存** → **测试连接**，看到「连接成功 ✅」即可。

> 🔒 密钥保存在本机 `secret.local.json`，**不会**被分享出去（已在 `.gitignore`）。每个人填自己的。

### STEP 2 · 上传文章

把 `.docx` 或 `.md` 文件拖进上传框（或点击选择）。规则：
- **一个文件 = 一篇文章**
- **第一行（Word 的首段）= 标题**，其余 = 正文
- Word 里的**加粗、标题层级、内嵌图片、表格**都会被识别保留

### STEP 3 · 勾选平台

勾掉你**不发**的平台即可——不是每个平台都必须发。四个平台可任意组合。

### STEP 4 · 开始发布

点「🚀 开始发布」，工具会按勾选平台，依次发 `articles/` 里**所有还没发过**的文章（已发过的自动跳过）。下方实时滚动日志。

> **首次发某平台会弹出 Chrome 让你手动登录**——见下一节。

---

## 三、关于登录（重要）

本工具**不保存任何账号密码**。它给每个平台开一个**独立的浏览器档案**（存在本工具目录的 `profiles/<平台>/` 里），让你**手动登录一次**，之后就记住了。

**推荐：一键登录命令**（装好环境后先跑这个，之后发布就完全不用管登录）：

```bash
python3 login.py             # macOS / Linux: 逐个登录已启用的平台
py login.py                  # Windows
py login.py xueqiu zhihu     # 只登录指定平台
```

每个平台会弹出专属浏览器窗口 → 你在里面扫码/验证码登录 → 工具检测到登录态后自动关窗保存。

也可以不跑 login.py：第一次发布某平台时会弹窗让你登录，效果一样。

- 登录态只存在你自己电脑的 `autopub/profiles/` 目录（已 gitignore，不会进仓库）。
- 换电脑/重装：把 `profiles/` 目录拷走即可带走全部登录态。
- 遇到**验证码 / 滑块 / 安全验证**：在那个弹出的窗口里手动完成，程序检测到通过后自动继续。

> 自动化浏览器和你日常用的浏览器**完全隔离**——你平时用什么浏览器都行，互不影响。
> 内核选择见 `config.yaml` 的 `browser.channel`：默认工具自带的 Chromium；也可改成复用本机 Chrome 或 Edge。

> 拿到这份工具时它是**空白模板**，里面没有任何人的登录信息和文章——每个人首次使用都要自己登录一遍各平台。

## 四、发布结果

- 日志里每个平台会显示 ✅/❌ 和文章链接（链接是真正发成功的证据）。
- 所有勾选平台都发成功的文章，会自动移到 `articles/_done/`。
- 完整结果清单也写在 `logs/last_publish_summary.txt`。

## 五、不用网页？命令行也行

```bash
# 发全部勾选平台（config.yaml 里 enabled=true 的）
python3 publish_all.py

# 只发指定平台
python3 publish_all.py --platforms laohu,xueqiu

# 只发某一篇
python3 publish_all.py --file 你的文章.docx

# 看每篇在各平台的状态
python3 publish.py --status

# 校准模式：只填内容+截图、不真发（调排版用）
python3 publish.py --platform laohu --draft
```

## 六、调参数（不改代码）

打开 `config.yaml`：
- `throttle.min_interval_seconds`：每篇之间最小间隔（默认 60 秒，防风控）
- `throttle.max_consecutive_failures`：连续失败几次就停（默认 3）
- 各平台 `max_daily`：单次最多发几篇
- `stock_tags`：股票标签处理（`card` 插真卡片 / `strip` 转纯文本 / `keep` 原样）
- 知乎 `fill_chart_gaps`：是否用模型补图表文字（true/false）

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 弹出的 Chrome 一直停在登录页 | 在那个窗口手动登录；超时（约 4 分钟）会停，重发即可 |
| 发知乎图表位置没有文字 | STEP 1 没配模型 API，或测试连接没过；配好再发 |
| 「测试连接」失败 | 检查 model 名、base_url、key 是否正确，有没有挂代理 |
| 提示已有任务在跑 | 等当前发布结束，或点「停止」 |
| 想重发已发过的文章 | 该文章在 `state.json` 里记了已发；删掉对应记录再发 |

## 八、加一个新平台（开发向）

写 `publishers/<名字>.py`，继承 `BrowserPublisher`，填 4 样：`name` / `profile_dir` / `compose_url` / `logged_in_keywords`，实现 `publish_one(page, article, draft)`，然后在 `publishers/__init__.py` 注册即可。详见 `README.md`。
