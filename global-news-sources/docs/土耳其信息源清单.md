# 土耳其信息源清单（端点级，供外部项目接通）

> 导出时间 2026-08-31，全部端点当日在本机实测通过（curl/脚本复测，非代理转述）。
> 项目内实现见 `global-news-sources/fetchers/basic.py`（fetch_tcmb_*/fetch_kap_*/fetch_*_rss）
> 与 `fetchers/extra.py`（fetch_aa_morning/fetch_turkey_morning），注册表 id 附在每节标题后。
> 时区注意：土耳其 TRT = UTC+3（无夏令时），文中的作息均为当地时间。

## 一、法定披露与官方层（一手源，最高权威）

### 1. KAP 公开披露平台（`kap_disclosures`）⭐ 最重

土耳其上市公司**法定公告唯一官方入口**（Borsa Istanbul 旗下），财报/重大事项/股权变动全在这。

- **端点**：`POST https://www.kap.org.tr/tr/api/disclosure/members/byCriteria`
- **请求**：JSON body `{"fromDate":"YYYY-MM-DD","toDate":"YYYY-MM-DD","member":"","disclosureClass":""}`，带 `Referer: https://www.kap.org.tr/tr/`；无 key
- **响应**：JSON 数组（实测 3 天窗口约 433KB），字段 `publishDate`（"DD.MM.YYYY HH:MM"）、`stockCodes`、`kapTitle`（公司名）、`subject`
- **坑**：旧端点 `GET /tr/api/disclosure/list` 已 404（有代理误判"源已消失"），**必须 POST byCriteria**
- **作息**：近实时，周末也有公告

### 2. TCMB 央行新闻稿 Atom（`tcmb_press`）

利率决议（每月）、流动性操作、政策声明。

- **端点**：`GET https://www.tcmb.gov.tr/wps/wcm/connect/EN/TCMB+EN/Bottom+Menu/Other/RSS/Press+Releases`
- **格式**：Atom（`<entry>` 结构）。**三个坑**：① Content-Type 标 `text/html` 但 body 是合法 Atom，别按 HTML 解析也别因此丢弃；② `<title>` 内容被 CDATA 包裹，通用 HTML 剥离会把标题整段吃掉，要先解 CDATA；③ 日期格式 `Aug 28, 2026, 5:23:07 PM`（`%b %d, %Y, %I:%M:%S %p`），是 UTC+3 本地时间
- **作息**：事件驱动（议息日必更）

### 3. TCMB 每日汇率牌价（`tcmb_fx`）

USD/EUR/GBP/JPY/CNY 等兑 TRY 官方现汇买卖价。

- **端点**：`GET https://www.tcmb.gov.tr/kurlar/today.xml`（固定文件名，每日覆盖）
- **格式**：XML，根节点 `Tarih="DD.MM.YYYY"` 属性是牌价日期，币种在 `<Currency CurrencyCode="USD">` 下的 `<ForexBuying>/<ForexSelling>`
- **语义**：非交易日文件不更新（日期头不是今天 = 正常空数据，不是故障）
- **作息**：交易日约 15:30 TRT 更新一期

### 4. TCMB EVDS2 宏观序列 API（`tcmb_evds`，备用，需 key）

利率/通胀/汇率全量宏观时间序列（官方数据门户）。

- **端点**：`GET https://evds2.tcmb.gov.tr/service/evds/?series=TP.DK.USD.A&startDate=DD-MM-YYYY&type=json&key=<KEY>`
- **key**：免费，`https://evds2.tcmb.gov.tr` 注册即得
- **注意**：日期参数格式是 `DD-MM-YYYY`；响应 items 里数值列名 = 序列代码把 `.` 换成 `_`（如 `TP_DK_USD_A`），日期在 `TARIH` 字段
- **状态**：本项目内停用占位（没配 key），端点本身可用

## 二、快讯层（RSS，零 key，分钟级）

| 源 | 端点 | 语言 | 特征 |
|---|---|---|---|
| CNBC-e（`cnbce_rss`） | `https://www.cnbce.com/rss` | 土语 | **单次约 250 条**，5 分钟级刷新，量最大 |
| Foreks（`foreks_rss`） | `https://www.foreks.com/rss/` | 土语 | 本土财经数据商；`/haberleri` 页面已死，只剩 `/rss/` 可用 |
| Dünya 世界报（`dunya_rss`） | `https://www.dunya.com/rss` | 土语 | 主流财经日报，5 分钟刷新 |
| Daily Sabah（`dailysabah_rss`） | `https://www.dailysabah.com/rssfeed/business` | **英文** | 财经/经济政策，日内高频 |
| Hürriyet Daily News（`hurriyet_rss`） | `https://www.hurriyetdailynews.com/rss/news` | **英文** | 带全文摘要；**`/rss/business` 2026-04 起停更（HTTP 200 但内容死）、根 `/rss` 是空壳**，只有 `/rss/news` 活跃（混时政需下游筛） |
| Sabah 经济频道（`sabah_rss`） | `https://www.sabah.com.tr/rss/ekonomi.xml` | 土语 | 宏观日程/政策，日更约 10 条 |

**通用解析坑**（全部适用）：`pubDate` 用 RFC 2822 主解析 + ISO 8601 兜底；标题可能包 CDATA；`r.encoding = r.apparent_encoding` 防土语乱码（ç/ğ/ı/ö/ş/ü）。

## 三、晨报/聚合层（英文+土语，日更一篇）

### 7. AA 安纳多卢通讯社 Morning Briefing（`aa_morning`）

土耳其国家通讯社的英文晨报，全球+土耳其混合，每日一篇长文。

- **发现链**（无固定 URL，需三级兜底）：
  1. `GET https://www.aa.com.tr/en/search?s=Morning+Briefing`（搜索页找最新一篇 slug）
  2. 兜底 `https://www.aa.com.tr/en/rss/default?cat=world`（RSS 里找 Morning Briefing 标题）
  3. 再兜底 `https://www.aa.com.tr/en/world`（列表页）
- **文章 URL 形态**：`https://www.aa.com.tr/en/{section}/{slug}`，找到 slug 后拼，正文 HTML 解析
- **作息**：每日一篇（英文，约 7500 字）

### 8. BloombergHT 土耳其市场汇总（`turkey_morning`）

本土财经电视网，三部分：突发快讯 + 要闻 + 当日收盘综述。

- **快讯/要闻**：`GET https://www.bloomberght.com/borsa`（HTML 解析，锚点文本 `SON DAKİKA` 区块取 `/sondakika` 链接、`Öne Çıkan` 区块取 `-\d+` 结尾的文章链接）
- **收盘综述**：`GET https://www.bloomberght.com/tum-piyasa-haberleri`，找 href 含 `piyasalarda-gunun-ozeti` 或 `piyasa-ozeti` 的链接；**日期在 slug 里且月份是土耳其语**（`31-ağustos-2026`，需土语月份映射表）；正文在 `<article class="...news-content...">` 容器，匹配不上就跳过（整页兜底全是广告脚本）
- **请求头**：建议带 `Accept-Language: tr-TR,tr;q=0.9`
- **作息**：快讯近实时，综述每交易日收盘后

## 四、接通建议

1. **只做快讯聚合** → 第二节 6 个 RSS 够用，解析一套通吃（注意上面通用坑）
2. **要法定公告** → KAP 是必须项（唯一官方入口），别浪费时间找替代
3. **要宏观数据** → EVDS2 申个免费 key；每日牌价用 today.xml 零 key
4. **要英文早报内容** → AA Morning Briefing + Daily Sabah + Hürriyet 组合
5. 本项目实测环境：中国大陆出口，以上端点**全部直连可达**（2026-08-31）
