# 行情数据源清单（对外复用版）

> 从 ai-auto-gen 注册表（107 源）中筛出的**行情/数据类**源，全部实测可用（除标注"占位"者）。
> 口径 2026-08-31。每个源给：端点 / 方法 / 鉴权 / 返回格式 / 作息 / 字段与坑。
> 本项目实现见 `generator/sources.py`、`generator/extra_sources.py`（Python requests，可直接抄）。

## 一、指数/行情快照

### 1. 新浪 hq 行情接口（A股指数 + 全球指数，零 key）
```
GET https://hq.sinajs.cn/list=sh000001,sz399001,sz399006,sh000688
GET https://hq.sinajs.cn/list=gb_dji,gb_ixic,gb_inx,hkHSI,hkHSTECH,gb_n225,gb_dax,gb_ukx
Referer: https://finance.sina.com.cn/   ← 必须带，否则 403
```
- 返回：GBK 编码文本 `var hq_str_sh000001="...";`，逗号分隔字段
- 字段坑：**A股** parts[1]=今开、[2]=昨收、[3]=最新价；**gb_ 全球指数** parts[1]=现价、涨跌幅在后续位；hk 系另排
- 作息：盘中实时；实现 `generator/sources.py fetch_cn_index_snapshot`（A股四指数）、`generator/extra_sources.py fetch_global_markets`（8 个外围指数：道/纳/标/恒指/恒科/日经/DAX/富时）
- 个股同样可用：`list=sh600519`、`hk00700`、`gb_aapl`

### 2. 东财 push2 行情集群（板块榜，零 key）
```
GET https://17.push2.eastmoney.com/api/qt/clist/get
    ?fs=m:90 t:2 f:!50   ← 行业板块(概念用 t:3)
    &fields=f12,f14,f3,f104,f105   ← 代码,名称,涨跌幅%,上涨家数,下跌家数
    &fid=f3&po=1&pz=10             ← 按涨跌幅排序取 Top10
```
- 返回：JSON `data.diff[]`
- 作息：盘中实时
- 坑：push2 集群会成片失联（2026-08-31 实踩），**必须备第二风控面**；本项目备胎=新浪行业榜 `https://money.finance.sina.com.cn/q/view/newSinaHy.php`（其字段[5]涨跌幅**已是百分数**，别再乘 100）
- 实现：`fetch_em_sector_board` / `_em_board` / `_sina_industry_board`

### 3. 台湾证交所/柜买中心 OpenAPI（零 key，官方）
```
GET https://openapi.twse.com.tw/v1/news/newsList        ← 新闻(我们在用)
GET https://openapi.twse.com.tw/v1/opendata/t187ap05_L  ← 上市月营收(未收, 备用)
GET https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap05_O  ← 上柜月营收(备用)
同族 50+ 数据集(行情 MI_INDEX 等), 契约: openapi.twse.com.tw/v1/swagger.json
```
- 返回：JSON 数组；**日期是民国年**（1150830 = 2026-08-30，+1911）

## 二、汇率

### 4. Frankfurter（ECB 参考汇率，零 key）
```
GET https://api.frankfurter.dev/v1/latest?base=USD
```
- 返回：JSON `rates{}`；交易日一更；**不含 TWD**

### 5. 土耳其中行每日牌价（零 key，官方）
```
GET https://www.tcmb.gov.tr/kurlar/today.xml
```
- 返回：XML，`<Currency CurrencyCode="USD"><ForexBuying>/<ForexSelling>`（现汇买/卖）
- 作息：交易日约 15:30（土耳其时间）一更；非交易日返回空（正常）

## 三、利率/债券

### 6. 纽约联储 Markets API（SOFR/EFFR/OBFR/TGCR，零 key，官方）
```
GET https://markets.newyorkfed.org/api/rates/all/latest.json
```
- 返回：JSON `refRates[]`，取 `type`+`percentRate`+`effectiveDate`

### 7. 美债收益率曲线（零 key，官方）
```
GET https://home.treasury.gov/resource-center/data-chart-center/interest-rates/
    TextView?type=daily_treasury_yield_curve&field_tdr_date_value_month=<YYYYMM>
```
- 返回：HTML 表格（3M/2Y/10Y/30Y 各期限）；日更
- 实现：`fetch_treasury_yield_curve`（含 10Y-2Y 利差计算）

### 8. 美国债总额（Fiscal Data，零 key 免注册）
```
GET https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v2/accounting/od/debt_to_penny?sort=-record_date&page[size]=5
```
- 工作日 T+1；同 API 另有 avg_interest_rates 等数十张表

## 五、财报/事件日历

### 11. Nasdaq 财报日历（零 key）
```
GET https://api.nasdaq.com/api/calendar/earnings?date=<YYYY-MM-DD>
User-Agent: 浏览器 UA 必须
```
- 当日披露公司+预期 EPS；周末/假期空属正常（不是故障）

### 12. 华尔街见闻宏观事件日历（零 key）
```
GET https://api-one-wscn.awtmt.com/apiv1/finance/macrodatas?start=<unix>&end=<unix>
Referer: https://wallstreetcn.com/calendar
```
- 返回 JSON `data.items[]`：`public_date/country/title/importance/forecast/actual`；我们按 importance>=2 过滤当日
- 实现：`fetch_calendar`

## 通用坑位提醒

1. **新浪 hq 必须带 Referer + GBK 解码**；央视/部分中文站 requests 会误判 Latin-1，要 `r.encoding = r.apparent_encoding`
2. **东财 push2 集群会成片掉线**，重要行情至少双风控面（东财主+新浪备）
3. **新浪行业榜涨跌幅已是百分数**（2.4159 = +2.42%），乘 100 会变成 +241%
4. 台湾官方 API **日期全是民国年**（+1911 转公元）；TWSE 部分键名带尾部空格（`"主旨 "`）
5. 周末/假期财报日历、汇率牌价返回空是**正常空数据**，不要当故障重试
6. 限速备查：东财每秒 >5 次/并发 ≥10/分钟 ≥200 次会封 IP；当前全部低频单发无压力
