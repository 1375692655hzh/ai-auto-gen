# 翻译/精标 LLM 实测矩阵与推荐模型（2026-09-02）

> 测试方法：生产同款提示词（`translate.py` 的 `_SYS`），三道样本题（英文快讯 / 土耳其语快讯 / X 脏乱帖俚语）+ 一道批量题（3 条带 title_zh，含繁体），每模型记录耗时、输出干净度、指令遵循（@账号/$TICKER/#话题/URL 不译）。
> 测试口径：`glm-5-3-flash` 经 arkcli（Responses API），免费池模型经 opencode CLI（Zen 免费池）。同一提示词逐题跑。
> 结论有效性：模型迭代快，换主力前建议用本文件末尾的复测脚本重跑一遍再拍板。

关键细节：
- **MiniMax 的 think 污染**：输出带明文 `<think>…</think>`，现有正则 `\[.*\]`（re.S 贪婪）恰好能兜住大部分，但 @handle 被译成中文是硬伤，无法后处理修复。
- **免费池（opencode CLI）不是 HTTP 端点**：Zen 免费模型走 opencode 子进程（每次 3-5s 启动开销 + 队列波动），**不适合做生产主力**。~~要接进 fallback 链要么申请 Zen HTTP key，要么 `opencode serve` 起本地端点。~~ **2026-09-04 已解决：OmniRoute 本地网关（`npm i -g omniroute && omniroute serve --daemon`，127.0.0.1:20128）给 Zen/OpenCode Free 池提供了 OpenAI 兼容 HTTP 端点，零 key 直调 `oc/muse-spark-1.2-contributor-free`，已作为备胎1 上线**（复测：三样本题 14.7s、JSON 干净、@handle/$TICKER 全保留；端到端实翻 4 条真实条目入库，术语 LNG/RBI 均正确）。注意 OmniRoute 需常驻运行，未启动时该链位秒级连接失败自动落备胎2，无副作用；机器重启后需重新 `omniroute serve --daemon`（可挂任务计划自启）。
- **glm-5.3-flash 慢的原因**：思维链较长（reasoning_content 明显），但质量同第一梯队且走套餐额度不另花钱。

## 二、推荐配置（translate.py / llm_tag.py 通用思路）

**主力 + 两条备胎的 fallback 链**，全部走 OpenAI 兼容 `/chat/completions`：

| 链位 | 模型 | base_url | key 来源 |
|---|---|---|---|
| 主力 | deepseek-v4-flash | 全局（secret.local.json 的 base_url，火山 Ark 套餐端点） | 全局 api_key |
| 备胎1 | oc/muse-spark-1.2-contributor-free | http://127.0.0.1:20128/v1（OmniRoute 本地网关，免费池） | 任意占位（本地端点不校验） |
| 备胎2 | glm-5.3-flash | 全局（同火山 Ark 套餐） | 全局 api_key |

**配置写法**（`config.yaml` 的 `sources.translate.models` 列表，`config.local.yaml` 同段覆盖）：

```yaml
sources:
  translate:
    enabled: true
    # 模型链: 依次尝试, 前一个失败自动切下一个, 成功后粘性沿用
    # 每项 base_url/api_key/model 三个字段都可自填; 留空 = 继承全局配置
    #   (base_url/api_key 继承 auto-publisher/autopub/secret.local.json 的 base_url/api_key)
    models:
      - model: deepseek-v4-flash          # 主力: 全局 key, 只填模型名
      - base_url: http://127.0.0.1:20128/v1   # 备胎1(免费): OmniRoute 本地网关
        api_key: omniroute-local          #   本地端点不校验, 占位即可
        model: oc/muse-spark-1.2-contributor-free
      - model: glm-5.3-flash              # 备胎2: 全局 key(火山套餐内)
    batch: 10
    max_chars: 1500
    round_cap: 120
```

行为约定：
- `models` 为空 → 退回旧单模型行为（`model: deepseek-v4-flash` + 全局 key），完全向后兼容。
- 某链项 `base_url`/`api_key` 留空 → 用全局值；`model` 留空 → 用 `deepseek-v4-flash`。
- 整批 10 条只在**全链都失败**时才计 fail/zh_attempts+1；单个模型失败静默切下一个，错误进报告 `errors`。
- 报告新增 `model_used` 字段：实际生效的链位标签（`#1:deepseek-v4-flash` 形如）。
- `zh_cache.model` 列记录实际生成译文用的链位标签，可追溯译文出自哪个模型。
