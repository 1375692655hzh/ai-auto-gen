# 美股早报源调研报告

- **调研日期**：2026-08-30（UTC，周日；美股周末休市，晨报类内容最后更新为周五 8/28，正好可用于验证周末停更规律）
- **实测环境**：Windows Git Bash + curl 8.x，UA = `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36`（下称"标准 UA"），未带任何 cookie
- **调研方法**：Grok Build CLI 联网背景调研（候选发现 + 官方发布时间佐证）+ 本地 curl / WebFetch 逐一实测交叉验证。所有 HTTP 状态码、时间戳均为实测，标注"来自 Grok Build"的为 Grok 检索结论（未逐一复测的会注明）
- **用途**：为"每日抓取同行早报整篇 → LLM 汇总成中文早报"流水线选源，对标富途《港美早报》（盘前发布、隔夜美股大盘/个股/宏观/今日展望）

## 2. 每源详情

### 2.1 CNBC Daily Open —— 首推 ★

**定位**：CNBC International 的每日晨报专栏（APAC/EMEA 两版），内容正是"隔夜美股回顾 + 股指期货 + 宏观事件 + 今日展望"，与富途《港美早报》同型。

**实测记录**：

```
$ curl -sS -A "<标准UA>" -L -o do.html -w '%{http_code}|%{content_type}|%{size_download}' \
    'https://www.cnbc.com/daily-open/'
200|text/html|1022557
```

- 归档页为 SSR HTML（1MB），文章列表直接在 HTML 里，无需 JS 渲染
- URL 规律（实测连续 7 个工作日 8/20–8/28 无断更；8/29、8/30 周末无新文章）：
  ```
  https://www.cnbc.com/2026/08/28/cnbc-daily-open-tariffs-in-spotlight-and-trump-has-a-new-name-for-a-lake.html
  https://www.cnbc.com/2026/08/27/cnbc-daily-open-nvidia-ai-results.html
  https://www.cnbc.com/2026/08/26/cnbc-daily-open-canada-trade-us-iran-strait-of-hormuz.html
  ...
  正则：https://www\.cnbc\.com/\d{4}/\d{2}/\d{2}/(cnbc-)?daily-open[a-z0-9-]*\.html
  ```
- 发布时间（归档页 SSR 内嵌 `"datePublished"` 实测序列）：
  ```
  2026-08-28T06:14:12+0000 / 2026-08-28T01:19:27+0000
  2026-08-27T06:10:58+0000 / 2026-08-27T01:11:19+0000
  2026-08-26T06:20:52+0000 / 2026-08-26T01:02:32+0000
  2026-08-25T06:03:28+0000 /（queryly 另见 08-25T01:07:35）
  ```
  → **每工作日两版：约 01:00–01:20 UTC（APAC 版）+ 06:00–06:20 UTC（EMEA 版）**。APAC 版北京时间早上 9 点出头即可抓到，时间上与本项目早报生产链路完美衔接。
- 文章正文实测（8/28 版）：

```
$ curl -sS -A "<标准UA>" -L -o art.html 'https://www.cnbc.com/2026/08/28/cnbc-daily-open-tariffs-...html'
200 | 911KB
# 去掉 <script>/<style> 后剥标签：可见文本 6776 字符，标题、正文、小节完整
```

**备用发现通道（结构化，更快）——queryly JSON API**（CNBC 站内搜索用的第三方服务，key 公开在前端）：

```
$ curl -sS 'https://api.queryly.com/cnbc/json.aspx?queryly_key=31a35d40a9a64ab3&query=daily%20open&endindex=0&batchsize=10&sort=date'
200 | application/json
```

返回结构（关键字段）：

```json
{
  "metadata": {"q": "daily open", "totalresults": ...},
  "results": [
    {
      "title": "CNBC Daily Open: Washington escalates on two fronts; Nvidia earnings in focus",
      "datePublished": "2026-08-25T01:07:35+0000",
      "cnbcUrl": "https://www.cnbc.com/2026/08/25/trump-bessent-us-sanctions-iran-canada-tariffs-nvidia-.html"
    }
  ]
}
```

**解析要点**：
- 发现层：归档页正则抽 `daily-open*.html` URL + `"datePublished":"..."`（二者都在 SSR HTML 中）；或 queryly `results[]` 的 `title / datePublished / cnbcUrl`
- 正文层：文章页 Next.js SSR，删除 `<script>/<style>` 块后剥标签即得全文；正文从标题 "CN Daily Open: ..." 之后、导航菜单之后开始（建议从 "Markets Pre-Markets ..." 导航文本之后截取）
- 时间字段：`datePublished`（ISO8601 带时区）

**风险与备援**：queryly 是第三方接口，key/端点有变更风险——归档页 HTML 通道作冗余；两条通道均免登录。

**反爬等级：low**（全程 curl + 普通 UA 直拉 200，无 Cloudflare 挑战、无 cookie 要求；注意控制频率即可）。

### 2.2 CNBC「5 things to know before the stock market opens」（盘前晨报）★

**定位**：CNBC 美国本土盘前晨报（Grok 注：即邮件产品 Morning Squawk 的网页版），"开市前五件事"结构：隔夜回顾 + 期货 + 个股 + 数据日历。

**实测记录**：
- 文章页（8/28 版）：`200 | 951KB`，去脚本后可见文本 9879 字符，含完整正文：

  > "...morning following a winning day on Wall Street. Here are five key things investors need to know to start the trading day: 1. Warsh-oming Federal Fed Chairman Kevin Warsh will deliver a keynote speech from ... Jackson Hole, Wyoming, this morning ..."

- 发布规律（queryly 按 `datePublished` 实测，注意这是"最后更新时间"，该文日内滚动更新）：

  ```
  2026-08-28T12:29:14Z  2026-08-27T15:01:14Z  2026-08-26T23:48:13Z
  2026-08-24T12:41:21Z  2026-08-24T12:15:02Z  2026-08-24T11:54:20Z
  2026-08-21T12:26:21Z  2026-08-19T12:34:20Z  2026-08-18T16:51:53Z
  ```
  → 工作日 **12:15–12:40 UTC（8:15–8:40 ET）** 为主要发布/更新窗口；周五后无更新（周末停）
- URL 固定模式（发现方式与 Daily Open 相同，走 queryly 搜标题）：`/YYYY/MM/DD/5-things-to-know-before-the-stock-market-opens.html`

**反爬等级：low**。与 Daily Open 共用同一抓取管道（queryly 发现 → 文章页取正文），工程上几乎零额外成本。

### 2.3 华尔街见闻 美股频道快讯（中文补充）

**定位**：7×24 中文快讯流，覆盖隔夜美股/全球宏观。**不是成篇晨报**，但免登录 JSON 极稳定，适合作为 LLM 的中文素材流或"隔夜要闻"拼装原料。

**实测记录**：

```
$ curl -sS -A "<标准UA>" 'https://api-one.wallstcn.com/apiv1/content/lives?channel=us-stock-channel&limit=5'
200 | application/json | 10092 bytes
```

返回结构（关键字段）：

```json
{
  "code": 20000,
  "data": {
    "items": [
      {
        "title": "OpenAI将终止向Cursor提供模型服务，马斯克回应：毫不在意",
        "content_text": "……正文全文……",
        "display_time": 1788057205,
        "uri": "https://wallstreetcn.com/livenews/3157327"
      }
    ],
    "next_cursor": "..."
  }
}
```

**解析要点**：
- `display_time` 为 Unix 秒级时间戳；`content_text` 即快讯全文；`next_cursor` 可翻页
- channel 参数实测：`us-stock-channel` 有效（内容以美股/国际宏观为主，混有部分全球时政）；`us-stock`（无 `-channel` 后缀）返回空 `items`；`global` 为全球频道
- 内容混有全球时政（伊朗/俄乌等），LLM 汇总时需按项目分类逻辑过滤

**注意**：`https://wallstreetcn.com/rss` 已失效（返回 200 但 content-type=text/html，为普通页面非 RSS）。

**反爬等级：low**（免登录；公网 API，RSSHub 同款接口。建议请求间隔 ≥30s，高频可能有未知的限流）。

### 2.4 CNBC Markets RSS（补充流）

**实测记录**：

```
$ curl -sS 'https://search.cnbc.com/rs/search/combinedcms/view.xml?partnerId=wrss01&id=10000664'
200 | application/xml | 20082 bytes
```

- item 结构：`<title> / <link> / <description>（1-2 句摘要）/ <pubDate>`，标准 RSS
- 更新：全天滚动，周末也有（实测含周六条目）；盘前个股稿如 "Stocks making the biggest moves premarket: PayPal, Affirm..." 会进 feed
- 同族可用 feed：Top News `id=100003114`（同样实测 200）
- **定位**：标题流+短摘要，非晨报。只建议作为"盘前异动个股"补充素材，或用于兜底发现 5 things/Daily Open 入文

**反爬等级：low**（无需 UA 也可拉）。

## 3. 落选源及原因

- **Reuters（reuters.com/markets 及 daily briefing）**：实测 `401`（WAF 严防），旧 RSS 已全线死亡；唯一干净入口是 Morning Bid 播客 RSS `https://feeds.megaphone.fm/THRH7907651499`（音频，不适用，来自 Grok Build）
- **Yahoo Finance Morning Brief**：官方发布时间为工作日 6:00–6:30 ET（来自 Grok Build，官方订阅页），**但网页版已名存实亡**——topic 页 `https://finance.yahoo.com/topic/morning-brief/` 实测 200 但条目流非每日队列（最新条目 6 天前，带 "Morning Brief:" 前缀的条目停留在数月前，且混入周展望/软文）；无官方 RSS（`/topic/morning-brief/rss/` 404）；全站 RSS `news/rssindex` 可拉但为通用新闻流。文章页本身 SSR 可抓（实测任意文章 200、全文可得），**缺的是稳定的每日发现层**
- **Axios Markets newsletter**：实测 `403`（bot 墙）
- **Barron's Daily**：付费墙 + 无 RSS（来自 Grok Build），免登录不可行
- **feeds.a.dj.com 全系（RSSMarketsMain 等）**：实测冻结于 2025-01，已死
- **feeds.content.dowjones.io/public/rss/mw_marketpulse**：实测冻结于 2025-07，已死
- **Investing.com news_285（Most Popular）**：实测冻结于 2024-11，已死
- **Nasdaq `rssoutbound?category=markets`**：实测 200 可拉，但内容是 Motley Fool 供稿的个股观点文流（"Prediction: Here's How Much Chevron Will Increase Its Dividend..."），非晨报；"Opening Bell" 是 9:30 ET 敲钟仪式非晨报（来自 Grok Build）
- **finviz news.ashx**：实测 200（需 UA），但是外部媒体聚合的标题流（Barron's/MW/Bloomberg 外链），无官方 API，对"整篇晨报"需求价值低
- **Seeking Alpha `feed.xml`**：实测 200 可拉，但为全站分析师文章流，经典晨报《Wall Street Breakfast》不在 feed 中，正文抓取需登录（403 风险）
- **财联社 `cls.cn/v1/roll/get_roll_list`**：实测不带签名返回 `400` 空体；需逆向 `md5(sha1(字典序拼接 query))` 签名（来自 Grok Build 的社区文档），私有接口随时改版，维护成本高
- **华尔街见闻 `/rss`**：实测返回 HTML 非 RSS，已失效
- **Google News RSS 作发现层**（`news.google.com/rss/search?q=site:finance.yahoo.com "morning brief"`）：本环境 curl 连接失败（状态码 000，疑网络封锁），无法验证；且属二级间接源，不稳定因素多
- **CNBC 官方 RSS 目录页 `cnbc.com/rss-feeds/`**：现为 JS 渲染无内容（来自 Grok Build）；分类 RSS 需用本文给出的 search.cnbc.com 端点

## 4. 最终推荐 Top 2

### Top 1：CNBC Daily Open + 5 things（同一条管道）

- **免登录**：curl + 普通 UA 全程 200，无 cookie/无验证码
- **结构稳定**：双通道冗余——① `/daily-open/` 归档页 SSR HTML（正则抽 URL + datePublished）② queryly JSON API（`title/datePublished/cnbcUrl` 结构化字段）；文章页 SSR 全文，去脚本剥标签即得
- **真正的晨报型**：成篇文章，隔夜回顾 + 股指 + 个股 + 宏观 + 今日展望，与富途《港美早报》内容型态一致；每工作日固定两版（01:10 / 06:10 UTC），5 things 盘前 8:15–8:40 ET 更新
- **时间契合**：APAC 版北京时间 09:10 出稿，白天 EMEA 版补位，5 things 覆盖美东盘前——一天三个时点可选
- 风险：queryly 第三方接口可能变更（有归档页兜底）；注意礼貌性限频

### Top 2：华尔街见闻 us-stock-channel 快讯 JSON

- **免登录 + 结构最稳**：单一 JSON 端点，`title/content_text/display_time` 一次拿全，无 HTML 解析成本
- **内容**：7×24 中文快讯，隔夜美股+宏观密度高；虽非成篇晨报，但作为中文素材流与 CNBC 晨报互补，也可用于交叉校验关键数字
- 注意事项：混有全球时政类快讯，需靠 LLM 分类过滤；建议 ≥30s 请求间隔

**组合建议**：CNBC 晨报（成篇英文底稿）+ 华尔街见闻（中文快讯补充/校验）+ CNBC Markets RSS（盘前个股异动补充），即可覆盖"隔夜美股大盘/重要个股/宏观事件/今日展望"全部分类。
