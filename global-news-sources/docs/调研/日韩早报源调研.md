## 2. 每源详情（实测命令与结果）

### 2.1 日本 P1：Kyodo News「Japan Wire」RSS

**实测命令**
```bash
curl -sS -m 30 -A "$UA" -L -o kyodo.xml -w "%{http_code}|%{size_download}" \
  "https://english.kyodonews.net/list/feed/rss4kyodonews-fzone"
# 结果: 200 | 15763 字节
```

**返回结构（RSS 2.0，约 20 条/窗口）**
```xml
<channel>
  <title>Japan Wire by Kyodo News</title>
  <lastBuildDate>Sun, 30 Aug 2026 16:52:11 +0900</lastBuildDate>
</channel>
<item>
  <title>Kyodo News Digest: Aug. 30, 2026</title>
  <link>https://english.kyodonews.net/articles/-/83420</link>
  <description><![CDATA[<p>The following is the latest list of selected news summaries by Kyodo News.----------</p>
    <a href="...">Read full story here</a>]]></description>
  <pubDate>Sun, 30 Aug 2026 15:00:00 +0900</pubDate>
  <dc:creator>KYODO NEWS</dc:creator>
  <media:thumbnail url="https://english-kyodo.ismcdn.jp/mwimgs/..."/>
</item>
```

**解析要点**
- 标题：`<title>` 纯文本；链接：`<link>`；时间：`<pubDate>`（JST +0900）
- 摘要：`<description>` CDATA 内含 HTML `<p>` 导语（2-3句）+ 尾部 "Read full story here" 链接需剔除
- 作者来源：`<dc:creator>` 可识别 KYODO NEWS / AP News（AP 通稿可按需过滤）
- 文章页全文：`https://english.kyodonews.net/articles/-/{id}` 实测 200 / 43KB，正文直接在 HTML 中，**无付费墙**

**内容质量与注意**
- 通讯社级市场报道（交易日的 "Tokyo stocks end ..." 收盘报道、日元、BOJ 等都在此流中出现），但 feed 为**全类别混合**（体育/天气/AP 稿占比不小）
- 无 business 专属 feed：实测 `rss4kyodonews-business/-economy/-finance/-politics/-news/-mzone/-bzone` 全部 404，站点导航也无独立商业分区
- 下游需关键词过滤：`Tokyo stocks / Nikkei / yen / BOJ|Bank of Japan / JGB / GDP / trade / Topix`
- 更新规律：`pubDate` 按天分布（样本窗口）周日 14 条、周六 6 条 → 周末不停更；发布高峰 08-20 JST

### 2.2 日本 P2：Japan Times Business 分类 feed

**实测命令**
```bash
curl -sS -m 30 -A "$UA" -L -o jt_biz.xml -w "%{http_code}|%{size_download}" \
  "https://www.japantimes.co.jp/business/feed/"
# 结果: 200 | 26822 字节
```

> 注意正确路径是 `/business/feed/`（WordPress 分类 feed）；`/feed/business/` 是 404。

**返回结构（RSS 2.0，20 条/窗口）**
```xml
<item>
  <title><![CDATA[ Modi's developed-nation dream strains against India's growth gap ]]></title>
  <link>https://www.japantimes.co.jp/business/2026/08/30/modi-developed-india-growth/</link>
  <category>BUSINESS</category>
  <pubDate>Sun, 30 Aug 2026 16:30:00 +0900</pubDate>
  <jto:credit><![CDATA[ BLOOMBERG ]]></jto:credit>
  <jto:tag><![CDATA[ Narendra Modi, India ]]</jto:tag>
  <jto:author>Anup Roy</jto:author>
  <description><![CDATA[The ambition, branded Viksit Bharat — ...]]></description>
  <media:thumbnail url="..."/>
</item>
```

**解析要点**
- 时间：`<pubDate>`（JST）；分类：`<category>` 固定 BUSINESS
- 特色字段：`jto:credit` 直接标注通讯社来源（BLOOMBERG/Reuters 等），适合筛选；`jto:tag` 为主题标签
- 摘要：`<description>` 仅一句话；整篇需进文章页抓取

**风险与注意**
- 文章页实测 200 / 370KB（页面很重），正文在 HTML 中；但页面加载 **Piano 计量付费墙**（实测发现 `premium/piano_jt.js`、`premium-label` 标记）→ 高频抓整文有触发限额风险，反爬 medium
- 更新规律：样本按天分布 8/27:4、8/28:8、8/29(六):7、8/30(日):2 → 约 5 条/天，周末减量但更新
- 内容偏国际商业（Bloomberg/Reuters 通稿），日本本土市场条目占比一般，建议与 Kyodo 互补

### 2.3 日本 P3：NHK World News JSON API

**实测命令**
```bash
curl -sS -m 30 -A "$UA" -L -o nhk.json -w "%{http_code}|%{size_download}" \
  "https://www3.nhk.or.jp/nhkworld/data/en/news/all.json"
# 结果: 200 | 414749 字节
```

**返回结构（JSON，data 数组 397 条存量）**
```json
{ "data": [ {
    "id": "20260830_200",
    "title": "Emergency Warning for heavy rain in Fukui Pref. ...",
    "description": "The Meteorological Agency at one point issued level five ...",
    "categories": { "name": "JAPAN" },
    "updated_at": "1788066000000",
    "page_url": "/nhkworld/en/news/20260830_200/",
    "thumbnails": { ... }, "videos": { ... }
} ] }
```

**解析要点**
- 标题：`title`；时间：`updated_at` 为 **epoch 毫秒**（`created_at`/`public_at` 实测为空），`id` 前缀也编码了日期（`20260830_200`）
- 分类：`categories.name` ∈ {JAPAN(157), ASIA(77), WORLD(146), **BIZTCH(17)**}；`BIZTCH` = Biz/Tech，是商业过滤入口
- 摘要：`description` 62~317 字符（导语级，非全文）
- 文章页：`https://www3.nhk.or.jp` + `page_url` 实测 200 / 仅 8.8KB，极轻量，正文在 HTML 中，免费无墙

**定位**：零反爬、结构最干净，但 BIZTCH 量少（存量仅17条）且偏科技产业新闻，缺少每日指数收盘复盘。适合作日本宏观/产业补充源。旧 RSS 端点 `nhkworld/en/news/rss/all.xml` 已 404（官方已下线 RSS，改用此 JSON）。

### 2.4 韩国 P1：Yonhap（韩联社）英文版 RSS

**实测命令**
```bash
curl -sS -m 30 -A "$UA" -L -o yna.xml -w "%{http_code}|%{size_download}" \
  "https://en.yna.co.kr/RSS/news.xml"
# 结果: 200 | 64092 字节（101-102 条/窗口）
```

**返回结构（RSS 2.0）**
```xml
<channel><title>Yonhap News Agency | All News</title>
  <lastBuildDate>Sun, 30 Aug 2026 17:44:28 +0900</lastBuildDate></channel>
<item>
  <title><![CDATA[Samsung Electronics, SK hynix's corporate tax tops 11 tln won in H1]]></title>
  <link>https://en.yna.co.kr/view/AEN20260830002000320</link>
  <pubDate>Sun, 30 Aug 2026 12:49:06 +0900</pubDate>
  <dc:creator>Kim Boram</dc:creator>
  <description><![CDATA[SEOUL, Aug. 30 (Yonhap) -- Corporate taxes paid by Samsung Electronics Co. and S...]]></description>
  <media:content url="https://img.yna.co.kr/etc/inner/EN/2026/08/30/...jpg" type="image/jpeg"/>
</item>
```

**解析要点**
- 标题：`<title>` CDATA；时间：`<pubDate>`（KST +0900）；链接：`<link>` 文章 ID `AEN{日期}{序号}{desk码}`
- **desk 码过滤**：链接末 3 位是编辑部代码，实测经济类为 `320`（如 Samsung 税收、BOK、财政部长报道均 `...320`），国内/政治为 `315`。官方经济分类 feed 不存在（`/RSS/economy.xml`、`/RSS/business.xml`、`/rss` 均 404/400），用后缀 320 或标题关键词过滤
- 摘要：`<description>` 约 180 字符导语（以 `...` 截断）
- 文章页：`en.yna.co.kr/view/AEN...` 实测 200 / 68KB，**正文免费直接在 HTML 中**

**内容质量（本项目最匹配）**
- 每日 KOSPI 收盘报道链完整，实测周五（8/28）同一条 "Seoul stocks snap 3-day rise on tech slump" 的演进：
  - `(URGENT)` 15:33:53 → 无前缀 15:35:20 → `(LEAD)` 15:58:13 → `(2nd LD)` 16:32:17 KST
  - 汇率报道 "S. Korean won hits over 13-month high" 16:40 KST
- **需去重**：同一故事的 `(URGENT)/(LEAD)/(Nth LD)` 多版本并存，按去前缀标题相似度合并，取最晚版本
- 更新规律：按天分布 8/28:55、8/29(六):16、8/30(日):31 → 周末照常滚动；小时分布高峰 11-17 KST
- 早报抓取窗口建议：北京时间早 7-8 点抓取时，前日 15:30-16:40 KST 的收盘+汇率报道链已完整

### 2.5 韩国 P2：Korea Herald Business RSS

**实测命令**
```bash
curl -sS -m 30 -A "$UA" -L -o herald.xml -w "%{http_code}|%{size_download}" \

```

> 注意：老式地址 `/rss/business.xml`、`/rss/newsAll.xml` 返回 200 但是**空 channel 壳**（420字节），正确清单见 `/rss` 页面（kh_Business/kh_National/kh_World/kh_Opinion/kh_Kpop/kh_Sports/kh_LifenCulture）。

**返回结构（RSS 2.0）**
```xml
<item>
  <title><![CDATA[Korea tests Arctic route with first trial voyage in decade]]></title>
  <link>https://www.koreaherald.com/article/10856567</link>
  <pubDate>Sun, 30 Aug 2026 17:38:41 +09:00</pubDate>
  <author>The Korea Herald</author>
  <category>Business</category>
  <description><![CDATA[South Korea has launched its first government-backed container ship voyage
    through the Arctic in a decade, testing whether a route 35 percent shorter than the Suez ...]]></description>
  <media:content medium="image" url="https://wimg.heraldcorp.com/news/cms/..."/>
</item>
```

**解析要点**
- 时间：`<pubDate>`（+09:00，逐条真实时间）；分类：`<category>` 固定 Business
- **摘要即长文**：`<description>` CDATA 为数百词的完整导语段（接近正文前几段），即使不进文章页也可直接喂 LLM
- 文章页：`/article/{id}` 实测 200 / 97KB，正文在 HTML；页面有 `premium` 标记（部分深度稿收费），多数 Business 通稿可读 → 反爬 low-medium

**更新规律**：按天分布 8/27:14、8/28:21、8/29(六):3、8/30(日):12 → 工作日约 15-20 条/天，周末减量但更新；小时高峰 10-17 KST。

**内容质量**：晨报匹配度高——韩国财经日报主力，覆盖 KOSPI/KOSDAQ、三星/SK/现代、BOK 政策、出口数据；与 Yonhap 互补（Herald 有分析性报道，Yonhap 有快讯/收盘链）。

### 2.6 韩国 P3：Korea Times business feed（仅作全文补充）

**实测命令**
```bash
curl -sS -m 30 -A "$UA" -L -o kt_biz.xml -w "%{http_code}|%{size_download}" \
  "https://feed.koreatimes.co.kr/k/business.xml"
# 结果: 200 | 9224 字节（仅 3 条）
```

**结构**：RSS 2.0，`<title>`/`<description>`（CDATA，数百词**接近全文**）/`<link>`（带 `utm_source=rss`）/`<media:content>`。

**致命缺陷（实测）**
- 所有条目 `<pubDate>` 完全相同且等于 feed 生成时刻（business.xml 3 条全部 `09:27:03 GMT`；allnews.xml 100+ 条全部 `09:22:03 GMT`）→ **时间字段不可用于排序/增量判断**，只能靠 link 去重
- 每次刷新仅 3 条，覆盖量不足
- 主 feed `feed.koreatimes.co.kr/k/allnews.xml`（103KB）条目多但 `description` 只是标题重复，无摘要

**定位**：不独立使用；当 Yonhap/Herald 摘要不够长时，可用标题匹配从此源取整文。

## 4. 最终推荐

### 日本 Top 2
1. **Kyodo News「Japan Wire」RSS**（`english.kyodonews.net/list/feed/rss4kyodonews-fzone`）
   - 通讯社速度 + JST 时间戳 + 文章页免费全文 + 周末不停更；交易日的 Tokyo stocks 收盘报道、日元、BOJ 均覆盖。唯一代价是全类别混合需关键词过滤。
2. **Japan Times Business feed**（`japantimes.co.jp/business/feed/`）
   - Bloomberg/Reuters 通稿源（`jto:credit` 可筛），与 Kyodo 互补；注意文章页 Piano 计量墙，整文抓取需控频（建议每源每日 ≤10 篇、加缓存）。
   - 备选：**NHK World JSON**（`www3.nhk.or.jp/nhkworld/data/en/news/all.json`，取 `categories.name=BIZTCH`）——零反爬最稳定，作日本宏观/产业补充。

### 韩国 Top 2
1. **Yonhap 英文版 RSS**（`en.yna.co.kr/RSS/news.xml`）
   - 唯一提供完整"KOSPI 收盘报道链 + 汇率 + BOK"的英文免费源，101 条/3 天窗口含周末；按链接 desk 码 `320` 或标题关键词过滤经济条目；必须做 `(URGENT)/(LEAD)/(Nth LD)` 去重。
2. **Korea Herald Business RSS**（`koreaherald.com/rss/kh_Business`）
   - description 即数百词长导语（可不进文章页直接用），逐条真实 KST 时间戳；与 Yonhap 形成"快讯 + 分析"组合。
   - 备选：Korea Times `feed.koreatimes.co.kr/k/business.xml` 仅作全文补充（pubDate 不可用，靠 link 去重）。

### 接入提示（供后续实现参考）
- 时区：四源时间戳均为 KST/JST（+0900），入库统一转 UTC/北京时间
- 抓取时点：北京时间早 07:00-08:00 抓取可完整覆盖前日韩股收盘报道链（15:30-16:40 KST）与日本晚间报道
- 去重规则：Yonhap 前缀链 `(URGENT)→(LEAD)→(Nth LD)` 取最新版；Kyodo 的 AP 通稿与 JT 的 Bloomberg 通稿可能撞题，跨源按标题相似度去重
- 频控：JT/Herald 文章页有计量墙迹象，整文抓取建议每日限额 + 随机间隔；Kyodo/Yonhap/NHK 可放宽
