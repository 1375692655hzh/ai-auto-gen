# 找源调研：分析/观点类信息源

- **调研日期**：2026-08-30（周日）晚间，北京时间（以各站点服务器返回时间为准）
- **调研目标**：为"市场观点/机构研判"类内容寻找可程序化获取的信息源——机构观点（投行/券商研报摘要）、知名分析师/大V评论、媒体观点聚合专栏
- **实测环境**：Windows Git Bash + curl 8.x，UA = `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36`（下称"标准UA"），全程不带任何 cookie
- **与已有源的关系**：已有源全部为快讯/早报/行情类，本报告 4 个推荐源均为纯观点/研报形态，无重复；华尔见闻"名家"与已有的"早餐FM-Radio"同站不同栏目（已在正文标注）

### 2.1 东方财富研报中心 API —— 首推 ★

**定位**：data.eastmoney.com 研报频道的底层数据接口，直接吐 JSON：标题/机构名/研究员/发布日期/详情encodeUrl。宏观研究、策略报告、券商晨会纪要三个 qType 正是"机构研判"素材，且**全部带机构署名**。

**实测记录**（无 Referer、无 cookie，仅标准 UA）：

```
$ curl -s -A "<标准UA>" -o em.json -w '%{http_code} %{size_download}' \
  'https://reportapi.eastmoney.com/report/jg?pageSize=100&beginTime=2026-08-21&endTime=2026-08-28&pageNo=1&qType=3'
200 | 7244~13226 字节/页（pageSize 上限 100，pageNo 翻页）
```

注意：`/report/list` 端点对宏观返回 `hits:0`，**正确端点是 `/report/jg`**。

**列表 JSON 关键字段**（qType=3 实测样本）：

**14 天更新规律**（2026-08-17~30，首 100 条统计）：

- 晨会纪要（q4）：08-18二7 → 08-19三13 → 08-20四11 → 08-21五12 → **08-22六0 / 08-23日0** → 08-24一10 → 08-25二13 → 08-26三11 → 08-27四13 → 08-28五10 → **08-29六0 / 08-30日0**。纯交易日作息，零周末。
- 策略（q2，hits=149）：工作日 8-18 篇；周末周六 2 篇、**周日 8-23 出现 11 篇小高峰（券商周策略周日发）**、8-30 周日 3 篇。
- 宏观（q3，hits=129）：工作日 4-16 篇；周末 1-3 篇零星。
- 机构分布：中信证券经纪(香港) 16、开源 10、东莞 9、国信 9、东吴 7、第一创业 8、东海/金元/山西各 8-9（14 天窗口）。

**限制**：`publishDate` 只有日期没有时刻（早报抓取建议按"昨日+今晨"日期窗口拉取）；晨会纪要正文为当日晨间内容，实际发布时刻无法从 API 得知。

**质量评语**：作者辨识度满分（机构名+研究员实名）；观点密度高（晨会纪要=当日全所观点合集，策略周评有明确方向判断）；无广告软文混入。这是"机构研判"素材的最强免登录入口。

### 2.4 华尔街见闻·专栏流 API

**定位**：与已有源"华尔街见闻早餐FM-Radio"**同站不同栏目**——早餐是快讯日报，本源是专栏分析文章流（`accept=column`），标题与摘要大量转述机构观点（"巴克莱：棕榈油、橡胶、咖啡或在18个月内上涨30%-40%"）。

**列表 API 实测**：

200 | 45136 字节/页；cursor 翻页：&cursor=<ts>,<ts>（limit>20 返回空 data）
