# 找源调研：日报/晨报类（欧洲 / 港中概 / 印度东南亚 / 大宗加密汇市）

- 调研日期：2026-08-30（周日）实测；样本窗口 8/24～8/30，另用 sitemap 历史（1083 篇带日期 slug）回溯数月
- 调研方式：全部 curl（Chrome UA、免登录、无 cookie）实测，状态码/体积为真实记录；解析点用 python 解析确认
- 目标：找"同行早报"级成篇日报（隔夜回顾 + 今日展望 + 关键数字），填已有覆盖之外的空白市场
- 已有覆盖（禁重复）：A股(富途/财联社/见闻/gangtise)、美股(CNBC)、日本(共同社)、韩国(韩联社)、土耳其(AA+BloombergHT)

## 2. 每源详情

### 2.1 欧洲市场 P1：interactive investor（ii.co.uk）

英国头部券商平台的内容站，英国股指（FTSE 100/250）+ 英欧宏观 + 全球市场视角，正好补欧洲空白。

**实测证据**
```
GET https://www.ii.co.uk/news                                → 200 | 559,072 B（SSR，140 张文章卡）
GET https://www.ii.co.uk/analysis-commentary/market-snapshot-calm-american-storm-ii540076
                                                             → 200 | 200,255 B
GET .../market-snapshot-nvidia-effect-lifts-us-tech-stocks-ii540124 → 200 | 55,867 B
GET .../market-snapshot-holding-pattern-ahead-another-pivotal-day-ii540088 → 200 | 54,782 B
GET https://www.ii.co.uk/sitemaps/sitemap-index.xml          → 200
GET https://www.ii.co.uk/sitemaps/sitemap-analysis-commentary.xml → 200 | 2,679,891 B（22,320 URL，新→旧）
```

**栏目矩阵（sitemap 内 slug 关键字统计）**
- `daily-trading-flash`：1111 篇（slug 自带日期，如 `daily-trading-flash-10-most-traded-shares-28-august-2026-ii540129`）
- `market-snapshot`：709 篇（每日市场快照，head of markets 撰写）
- `must-read`：482 篇（每日必读/每周前瞻 `week-ahead`：488 篇）
- `eyeq`：510 篇（数据向短分析）

**解析点**
- 文章 URL：`/analysis-commentary/{slug}-ii{id}`（slug 无日期，靠 sitemap 顺序或文章内时间）
- 正文容器：`<section data-id="article-content">`（Chakra UI，SSR 直出全文）
- 发布时间：SSR JSON 内 `datePublished\":\"2026-08-28T09:01:02+0100\"`（BST 时区，北京 +7 夏令时）

**作息统计（实测）**
- Daily Trading Flash（slug 日期法，1083 个带日期样本）：
  - 8/10(一)～8/28(五) 连续 15 个工作日**每天一篇、无一缺失**；8/15-16、8/22-23 两个周末**零发布**
  - 最新 slug：8/28(五)；周日抓取时 sitemap 第一条 `insider-ftse-250-directors-lock-7-yield-ii540132` 实测 datePublished=2026-08-28T15:27 BST → 周末确认停更
- Market snapshot（取文章页 datePublished）：8/25(二) 08:41、8/26(三) 08:40、8/28(五) 09:01 BST → 北京 15:41/15:40/16:01；本周二三四(8/25-27)连发但 8/24(一) 无 → 非严格每日，约 3-5 篇/周
- 当日版可抓时点：Market snapshot 北京约 15:40-16:00 后；Daily Trading Flash 发布时刻未逐篇取样（slug 日期已证频率，接入后可从 datePublished 后验）

**质量评语**
- Market snapshot 是标准"隔夜回顾+今日关注点"结构（FTSE 收盘 + 美股隔夜 + 央行/数据日历展望），数字密度高
- 站内混杂大量个人理财/ISA/养老金内容，下游需按 slug 前缀（market-snapshot / daily-trading-flash / must-read / week-ahead）白名单过滤
- 无付费墙；robots.txt 明示 `Crawl-delay: 10` 且 **Disallow `/news/*-al*`**（Alliance News 通稿，含 london-briefing 系列勿抓）；`/analysis-commentary/*` 不在禁止列表

### 2.2 印度市场 P1：Livemint（Mint）

**实测证据**
```
GET https://www.livemint.com/rss/markets      → 200 | 36,213 B（35 条，覆盖 8/29-8/30 两天，周六日照常产出）
GET https://www.livemint.com/market           → 200 | 1,402,364 B
GET .../stocks-to-watch-on-august-31-m-m-cupid-aurobindo-pharma-ola-kp-green-engineering-among-shares-in-focus-11787932250299.html
                                              → 200 | 38,842 B（压缩传输）
```

**日报型栏目（三选均可）**
1. **Stocks to watch on {date}**：早间 watchlist（前收盘回顾 + 当日焦点股），JSON-LD `datePublished: 2026-08-30T07:01:11+05:30`（周日发周一版，= 北京 09:31）
2. **Mark to Market**：收盘综述专栏（topic 页客户端渲染，建议从 RSS 按标题匹配发现）
3. **Stock market prediction for tomorrow, {date}: Sensex, Nifty outlook**：收盘后次日展望（8/30 已发 8/31 版）

**解析点**
- 正文：JSON-LD `"articleBody":"Indian stock market investors are likely to track several companies on Monday..."` 全文内联（实测含完整英文正文数段）
- 时间：JSON-LD `datePublished`（IST +05:30，北京 +2.5）
- 发现：RSS `<item>`（title/link/pubDate CDATA 正常）；RSS 混大量荐股文（"Stocks under ₹100 / Buy or sell: ..."），需按上述三个栏目标题模式过滤

**作息统计（实测）**
- RSS 窗口：8/29(六) ≥11 条、8/30(日) ≥12 条 → 周末照常（印度财经媒体周末产出荐股/前瞻类，交易类栏目随交易日）
- "Stocks to watch"：Google News 检索到 8/24(一)、8/27(四)、8/30(日) 各期（每交易日一篇，周日晚提前发周一版）——样本 7 天内 3 期直接可见，节奏为交易日晨更
- 当日版可抓时点：北京 09:31 后（早班 08:30 之后的第一波补抓，或午后班）

**质量评语**
- Sensex/Nifty + 印度宏观（FPI 流向、RBI）纯印度视角，空白市场首选；英文，LLM 处理无压力
- 计量付费墙存在（页面 19 处 paywall 标记），当前 JSON-LD 给全文；建议低频（每日 1-3 篇）按栏目抓，勿全站爬

### 2.3 加密+宏观 P1：PANews（panewslab.com）

**实测证据**
```
GET https://www.panewslab.com/    (302→/zh) -L → 200 | 1,047,206 B（首页 SSR）
GET https://www.panewslab.com/zh/articles/01a046ac-1302-7055-9436-7ee484f785da
                                        → 200 | 54,960 B（华尔街早报 8/28 期）
GET https://www.panewslab.com/zh/articles/01a05022-dba4-7310-adde-97702798b4d0
                                        → 200 | 60,212 B
```

**两个日报栏目（SSR payload 实录）**
- **华尔街早报**（column 定义原文："每周一至五上午，聚焦宏观、美股、AI、贵金属与原油等方向，用数据复盘市场、用趋势把握先机"）：
  - 8/26(三) 04:56Z / 8/27(四) 04:46Z / 8/28(五) 04:40Z → **北京 12:40-12:56**，工作日全勤（样本 3/3）
  - 8/28 期正文实测 23 个长段落，标题"英伟达打破'财报日诅咒'…今晚杰克逊霍尔或定调下半年全局"，结构=隔夜美股收盘数据(道指/标普/纳指涨跌幅)+联储官员表态+今晚关注点，质量与 CNBC Daily Open 同级
- **PA日报**（加密日报）："PA日报 | BitGo宣布…；币安将上线…" 8/30(**周日**) 09:15 UTC = 北京 17:15 → 加密 7×24，周末照发

**解析点**
- 发现：首页 SSR 两处——①渲染卡 `<a href="/zh/articles/{uuid}">` + `<time datetime="...UTC">`；②Nuxt devalue payload（`"01a046ac-...uuid","title":...` 与 `publishedAt` 配对，适合直接解析 JSON）
- 文章页：JSON-LD `datePublished`（UTC，北京 +8）+ 正文 `<p>` SSR 直出
- 注意 payload 中偶有未来时间戳（预排内容），过滤 `publishedAt <= now`

**质量评语**
- 加密空白市场唯一直连可用的中文日报源（CoinDesk 429、The Block 非日报型）
- 华尔街早报与富途港美早报/CNBC 部分重叠，但发布在北京午间、含贵金属/原油与 AI 主题，可作午后班的美国隔夜二次校验源；PA日报纯增量
- 反爬 low；语言中文

## 4. 按市场空白度排序的 Top 3-4

1. **interactive investor（ii.co.uk）** —— 欧洲市场完全空白的唯一合格免费源：Market snapshot（每日快照）+ Daily Trading Flash（工作日全勤）双栏目，FTSE/英欧宏观/全球视角；注意北京 15:40 后才有当日 snapshot，配午后班/夜班。
2. **Livemint** —— 印度完全空白，"Stocks to watch"北京 09:31 即可抓当日版，是少数能赶上早班补抓的海外源；需按栏目标题过滤荐股噪音。
3. **PANews** —— 加密空白唯一直连中文日报（PA日报，周末照发）；附带"华尔街早报"（北京午间发布的高质量美股隔夜综述）可作美股二次校验。
4. **The Block RSS**（备选）—— 加密 flash 形态补充，非日报型，仅在需要加密快讯流时接入。

> 接入提醒（对照《源录入规范》）：ii 的 Market snapshot 北京 15:40-16:01 发布，早班 08:30 抓到的是昨日版（"仅补班可用"需在排程注明）；Mint watchlist 09:31、PANews 华尔街早报 12:40、PA日报 ~17:15，分别适配早班补抓/午后班/夜班。
