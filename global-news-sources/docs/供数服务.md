# 供数服务（单机数据站）操作手册

> 2026-09-01 落地（MoA 四方案收敛 + 用户 5 点拍板：读写分离 / SQLite+快照 / 进程分离调度 / X池30min+熔断 / 内网+隧道）。
> 形态：**一台设备 = 唯一抓取枢纽**（调度进程定时写库）；**其他人只读接口取数**，消费者永不触发抓取。

## 架构

```
[任务计划 每30min] → python cli.py sources refresh   （一次性进程, 到期源才真抓）
        ↓ 唯一写者（域名闸门+健康熔断）
data/serve/items.db   SQLite WAL 权威库（统一 Schema + 源四标签打平）
data/serve/refresh.json  刷新账本（每源状态/耗时/条数, 禁手编）
data/dist/latest.json.gz + by-market/*.gz + manifest.json   快照产物
        ↑ 读（WAL 无锁并发）
python cli.py sources serve   FastAPI 常驻只读服务
```

## 命令

| 命令 | 作用 | 副作用 |
|---|---|---|
| `python cli.py sources list [--markets 美股,台湾] [--channels ...] [--forms ...] [--json]` | 源清单（含四标签+健康），可按标签过滤 | 无 |
| `python cli.py sources gather [--markets/][--kinds/][--ids/][--fresh] [--json]` | 按标签聚合抓取（显式 --ids 不受 enabled 约束） | 会请求外网（TTL 内走缓存） |
| `python cli.py sources refresh [--dry-run] [--json]` | 到期源调度刷新 → 写服务库 + 快照导出 | **真抓外网**（排除聚合组/dead/浏览器登录态源/conf refresh:false） |
| `python cli.py sources serve [--bind 0.0.0.0] [--port 8787]` | 只读 HTTP 供数（默认 127.0.0.1） | 常驻进程 |

## HTTP 端点（全 GET，无写无刷新）

| 端点 | 说明 |
|---|---|
| `GET /v1/health` | 服务+库+最新快照状态 |
| `GET /v1/sources?markets=&channels=&forms=&kinds=` | 源档案（四标签/启用/健康） |
| `GET /v1/sources/{id}` | 单源档案+健康详情 |
| `GET /v1/items?markets=&kinds=&info_types=&event_types=&channels=&forms=&sources=&tickers=&sentiments=&q=&since=&limit=&cursor=&dedup=` | 条目多维过滤+关键词检索+游标分页（limit≤1000）。`dedup=1`(默认)同事件折叠只出代表条，`=0` 出全量带簇标记；`q` 拆词 AND 检索 |
| `GET /v1/snapshot/latest` | 全量 gzip 包（单独按次限流） |
| `GET /v1/status` | 刷新账本+库统计+dead 源清单 |

## 鉴权与配额

- 密钥文件 `global-news-sources/config/api_keys.local.json`（gitignored）：每键 `name/key/enabled/rpm/daily_items/daily_snapshot`
- 请求头 `Authorization: Bearer <key>`（或 `X-API-Key`）；**文件无键且 localhost 时免密**；有键后一律要带
- 超限 429 + Retry-After；访问日志 `data/serve/access.log`（不记正文不记全 key）
- **网络红线**：默认内网；跨网走 Tailscale/cloudflared 隧道；禁止 Windows 裸开公网端口

## 调度登记（Windows 任务计划）

```
程序: py -3.11

触发: 每 30 分钟, 勾选"错过后尽快补跑"
```

## 条目 Schema（item，v2）

必有 `id/source_id/source/time/text`；可选 `title/url/media`；
源标签打平进每条：`kind/form/channel/risk/markets[]/lang`；
信息标签：`info_type`（按 kind 缺省）+ **规则打标**（入库即打，零LLM）：`tickers[]`/`event_type`/`sentiment`/`sectors[]`（insight 类不打赛道）/`matched_terms`；
**M4 LLM 精标**：refresh 轮末批量 20 条/次精修 sectors/sentiment/event_type（deepseek-v4-flash 便宜档，失败保留规则标，config `sources.llm_tag.enabled:false` 关闭）；
时效：`time`（发布时间,归一北京时）+ `fetched_at`（入库时刻）+ `published_at_known`（1=源给的时间, 0=兜底）；
去重：`canonical_url`（规范化URL）+ `cluster_id/dup_count/dup_scope`（同事件簇, dedup=1 折叠展示）。

## 保留窗与运维

flash 48h / peer_article·announcement·market·calendar 7d（`store.prune()` 每日清理由 refresh 收尾顺带做）。
路径可用环境变量覆盖：`AAG_ROOT`（项目根）/ `GNS_DATA_DIR`（数据目录）——调度器 cwd 与开发目录不同时必须设。

## 消费方接入（同事侧两种姿势）

**A. 只消费数据（大多数同事走这条，不用跑抓取）**：
找数据站管理员要三样东西——**数据站地址**（内网 IP 或 Tailscale 地址，如 `http://192.168.x.x:8787`）、**API Key**、本文档。然后：

```bash
# 源目录（发现有哪些源、什么标签）
curl -H "Authorization: Bearer <KEY>" "http://<数据站>/v1/sources?markets=美股"
# 拉条目（市场/类型/赛道/时间窗组合过滤）
curl -H "Authorization: Bearer <KEY>" "http://<数据站>/v1/items?markets=台湾&info_types=filing&limit=100"
# 增量同步（带上次游标）
curl -H "Authorization: Bearer <KEY>" "http://<数据站>/v1/items?since=2026-09-01 08:00"
# 全量打包
curl -H "Authorization: Bearer <KEY>" -o latest.json.gz "http://<数据站>/v1/snapshot/latest"
```

同事的 agent 直接把这些 curl 包装成工具调用即可（JSON 进出，字段见上文 Schema）。

**B. 自己也跑全量（要生成/发布内容的同事）**：
git clone 全仓库 → 按 README 快速开始装依赖 → `python cli.py doctor` 自检 →
`python cli.py sources refresh` + `serve` 起自己的数据站。本机个性化用
`config.local.yaml`（调源开关）和 `config/twitter_pool.local.yaml`（私加账号），
与库更新零冲突。
