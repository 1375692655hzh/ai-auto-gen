# 成稿模型接入 grok CLI（本机订阅额度）

> 2026-09-11 上线。成稿模型链支持第二种引擎：除 OpenAI 兼容 API 外，可加 **grok CLI 模型位**，
> 走本机已登录的 [Grok Build CLI](https://x.ai)（xAI 订阅额度），不需要 API Key。
> 适用于：内容生成成稿、蹭蹭流量评论生成、copylab 视频拆解——三处共用同一条成稿链。

## 一、它是什么

- 成稿模型链里的一种链位，`引擎 = grok CLI`：免填接口地址与 API Key，模型可留空（用 CLI 默认 grok-4.6-build）
- 调用方式：服务端 spawn 子进程跑 `grok -p <提示词> --output-format json`，取信封里的 `text` 字段
- 计费：吃你 xAI 账号的订阅额度（实测一次最小调用约 $0.005；成稿调用提示词更长，费用相应更高）
- 强制护栏（防 agent 自主行为污染内容）：
  - `--disable-web-search`（禁联网搜索）+ `--no-subagents` + `--max-turns 2`
  - 系统提示词追加硬约束：只依据素材作答、数字必须逐字来自素材、不加解释

## 二、接入步骤（每台机器一次）

1. **安装 grok CLI**：默认装在 `~/.grok/bin/grok.exe`，确认它在 PATH 里（终端敲 `grok --help` 有输出即 OK）
2. **登录（OAuth，一次性）**：终端跑 `grok`，按提示完成授权
   - 授权页会在**系统默认浏览器**弹出；账号登在指纹浏览器里的，把终端打印的**授权 URL 复制到指纹浏览器打开完成**即可——回调只认本机端口，哪个浏览器完成都一样
   - 云指纹浏览器除外（localhost 回调够不着本机），那种在弹出的默认浏览器里直接登录一次
3. **验证登录态**：`~/.grok/auth.json` 存在即已登录，此后永远不再碰浏览器
4. 工作台 → 设置 → 成稿模型 → **「＋ grok CLI 模型位」** → 点该位的「测试连接」做就绪自检（检测 CLI 与登录态，不真跑会话）→ 保存

## 三、使用建议

- **位置放兜底**：单次调用 20 秒起步（agent 会话开销），把它排在 API 位之后——API 挂了/超时才轮到它，链式自动落位
- 思考开关/高级 JSON 参数对该引擎不适用（已隐藏）；想指定模型在该位的"模型(选填)"里填，透传 `-m`
- 分发提示：这是**机器绑定**能力——没装/没登录 grok CLI 的机器上，该链位自动跳过、不影响链上其它位

## 四、排障

| 现象 | 处置 |
|---|---|
| 测试连接报 `grok_cli_not_ready: 未找到 grok CLI` | 装 CLI 或把 `~/.grok/bin` 加入 PATH |
| 报 `未登录` | 跑一次 `grok` 完成 OAuth，确认 `~/.grok/auth.json` 出现 |
| 生成时日志 `[grok-cli] 超时` | 该位被跳过落下一链位；可把它往下排或检查本机 CLI 是否卡死 |
| 输出被解释文字包裹 | 已有 JSON 宽松解析器兜底；仍异常可把该位停用反馈 |
