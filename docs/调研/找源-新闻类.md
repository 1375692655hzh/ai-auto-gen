# 找源调研：新闻/快讯类（kind=flash）

调研日期：2026-08-30（周日）。验证手段：本机 curl 实测（本次网络可用）+ WebFetch 交叉验证。所有"实测"数据均为当日真实抓取结果。

## 二、每源详情

### 1. 金十数据快讯（中文，全球市场，P0）

**入口 A（最新 50 条，免 header）**
```
GET https://www.jin10.com/flash_newest.js
```
实测：HTTP 200，31169 字节。返回 JS 变量 `var newest = [...]`，JSON 在等号后，正则/eval 剥壳即可。

**入口 B（分页 API）**
```
GET https://flash-api.jin10.com/get_flash_list?channel=-8200&vip=1&max_time={YYYY-MM-DD HH:MM:SS}
Headers: x-app-id: bVBF4FyRTn5NJF5n / x-version: 1.0.0 / Referer: https://www.jin10.com/
```
实测：HTTP 200，20129 字节/页，21 条/页。`max_time` 传上一页最旧条目的 `time` 即可向历史翻页。`x-app-id` 是网页端固定公开值，非登录凭证。

**条目结构**
```json
{
  "id": "20260830175920298800",
  "time": "2026-08-30 17:59:20",          // 秒级，直接是目标格式
  "important": 0,                          // 1=重要，可用于精排加权
  "channel": [4, 5],                       // 频道分类
  "data": {
    "title": "",
    "content": "【博瑞医药：2026年半年度净利润同比增长243%】金十数据8月30日讯，博瑞医药发布2026年半年度报告，实现营业收入6.78亿元，同比增长26.17%；归属于上市公司股东的净利润5893.28万元，同比增长243.17%。"
  }
}
```
样例英文条目（中英混流，channel 区分）：`"time":"2026-08-30 18:54:39"`，content 为以色列国防军击毙哈马斯成员的英文快讯。

**密度**：newest.js 50 条覆盖 17:15:38 → 18:54:39，仅 99 分钟，折算 **约 700 条/天**；分页 API 一页 21 条/73 分钟折算约 415 条/天。保守表述 400-700 条/天。8 月 30 日为周日仍在滚动（实测即周日数据），周末无休。

**风险评语**：反爬 low。固定头即可，注意别高频轮询（建议 ≥60s 间隔）。缺点是含大量盘口/行情类短讯，需靠 `important` 与关键词过滤。金十有 VIP 分层（vip=1 参数为免费层），个别条目标记 VIP 但正文仍返回。

### 2. 华尔街见闻·快讯流（中文，全球市场，P1）

**入口**
```
GET https://api-one.wallstcn.com/apiv1/content/lives?channel=global-channel&limit=100
```
实测：HTTP 200，182466 字节，**单次 100 条**。免登录、无必需 header。翻页：响应 `data.next_cursor` 为 Unix 时间戳，作为下一次请求的 `cursor` 参数即可继续向历史回溯（实测错误 cursor 返回空 items，机制有效）。另有 `polling_cursor` 供增量轮询。

**条目结构**（关键字段）
```json
{
  "id": 2317984,
  "display_time": 1753856115,             // Unix 秒 → YYYY-MM-DD HH:MM
  "title": "章建平、方文艳大幅减仓美年健康",
  "content_text": "8月30日晚，美年健康发布2026年半年度报告。公司上半年实现营业收入38.44亿元，同比下降6.45%……",
  "content": "<p>…HTML…</p>",
  "channels": ["global-channel", "a-stock-channel", "xgb-channel"],
  "symbols": [], "tags": []
}
```
`content_text` 是现成纯文本，LLM 直接可用，无需剥 HTML。

**密度**：100 条覆盖 08-29 13:56 → 08-30 17:15（约 27 小时），**约 90-100 条/天**；周日滚动（实测即周日）。`channel` 可换 `a-stock-channel`（A股）、`us-stock-channel` 等细分。

**风险评语**：反爬 low，接口质量高。**注意厂商重叠**：项目已有"华尔街见闻早餐"（精选合集），本源是全天滚动快讯流，产品不同但内容有包含关系，接入后建议在精排做与早餐源的条目级去重。

### 3. LiveMint RSS（印度，P1）

**入口**
```
GET https://www.livemint.com/rss/news
```
实测：HTTP 200，37343 字节，35 条/次。标准 RSS 2.0。

**条目结构**
```xml
<item>
  <title><![CDATA[India sets first national standards for mortuaries, bans basement morgues]]></title>
  <pubDate><![CDATA[Sun, 30 Aug 2026 16:23:29 +0530]]></pubDate>
  <link>…</link>
  <description><![CDATA[…摘要正文…]]></description>
</item>
```
`pubDate` RFC822 带印度时区，`email.utils.parsedate_to_datetime` 一步转标准时间。

**密度**：35 条覆盖 08-29 17:57 → 08-30 16:23（约 46 小时），约 18 条/天，周六周日均滚动。另有 companies/industry/budget 等子频道 RSS 可叠加增量。

**风险评语**：反爬 low（RSS 即为公开分发渠道）。印度市场目前完全空白，Mint 是印度主流财经媒体，英文内容可直接进 LLM。密度中等，作为区域补充源合适。

### 4. 界面快报（中文，P2）

**入口**
```
GET https://www.jiemian.com/lists/4.html
```
实测：HTTP 200，83278 字节，SSR 直出 HTML，20 条/页。注意 `lists/2.html` 是普通文章列表（无时间戳），快讯必须是 **lists/4**（"快报"栏目）。

**条目结构**：每条为 `article/{id}.html` 链接 + `HH:MM` 时间文本（如 18:58、18:46、18:43……），**不带日期**，需拼当天日期；跨零点抓取有归错日风险，建议抓取时以页面上下文校验。

**密度**：页首 12 条覆盖 18:05 → 18:58（53 分钟），折算约 200-300 条/天，周日滚动。分页 URL 形如 `lists/4_2.html`（本次未逐一验证翻页深度，接入时确认）。

**备选入口**：第三方镜像 `https://feedx.net/rss/jiemian.xml`（实测 200，30 条，半小时更新一次，pubDate 完整），但依赖第三方稳定性，只作降级方案。

**风险评语**：反爬 low。缺点：HTML 解析成本高于 JSON 源、时间戳缺日期、快报偏社会+财经混合（含灾害预警等非财经条目），需过滤。

### 5. CNA RSS（东南亚·新加坡，P2）

**入口**
```
GET https://www.channelnewsasia.com/api/v1/rss-outbound-feed?_format=xml&category=6511
```
实测：HTTP 200，20126 字节，20 条/次（category=6511 为 business 类）。

**条目结构**：标准 RSS，`pubDate` RFC822 带 `+0800`（新加坡时区），如 `Sun, 30 Aug 2026 17:35:00 +0800`。

**密度**：20 条覆盖 08-29 05:59 → 08-30 17:35（约 36 小时），约 13 条/天，周末滚动。东南亚市场空白，CNA 是新加坡/东盟主力英文媒体。

**风险评语**：反爬 low。密度偏低，且是"business 新闻"而非秒级快讯流，适合作为东南亚区域补充。其他 category id 可叠加（asia 类等）。

### 6. Euronews RSS（欧洲，P3）

**入口**
```
GET https://www.euronews.com/rss?level=theme&name=news
```
实测：HTTP 200，31827 字节，50 条/次，`ttl=30`（官方建议 30 分钟轮询）。

**条目结构**：标准 RSS，`pubDate` RFC822 带 `+0200`（欧洲中部时区），如 `Sun, 30 Aug 2026 12:03:35 +0200`。

**密度**：50 条覆盖 08-27 09:13 → 08-30 12:03（约 3.1 天），约 15 条/天，周末滚动。

**风险评语**：反爬 low，但这是**泛欧综合新闻**（含视频条目、文化/旅游条目），纯财经占比低，欧洲财经空白若要填，建议用其 business 专题 feed（`name=business`，接入时验证）再评估。优先级最低。

## 四、Top3 推荐

1. **金十数据快讯**（P0）：中文财经快讯密度天花板（数百条/天）、时间戳秒级现成、双入口互备、反爬 low。唯一准备工作是 `important`+频道过滤压噪。
2. **华尔街见闻·快讯流**（P1）：单次 100 条结构化最干净（`content_text` 纯文本 + title + channels 打标），免登录免 header，`next_cursor` 支持历史回溯。注意与已有早餐源做条目级去重。
3. **LiveMint RSS**（P1）：印度空白市场零成本首发，标准 RSS + 带时区秒级时间戳，反爬 low，可多子频道叠加密度。

界面快报（P2）为第四顺位：密度高但需 HTML 解析且时间戳缺日期；CNA（P2）补东南亚；Euronews（P3）仅在需要欧洲综合新闻时考虑。
