# 数据站接入指南（同事版）

> 数据站 = 7×24 自动采集全球财经资讯的中心服务，你只需要一个地址和一把 Key。

## 一、工作台接入（推荐方式）

如果你用的是工作台（图文/资讯页面）：

1. 打开工作台 → **设置页** → **信息源连接**
2. 连接模式选 **「云端数据站」**，填两格：
   - **数据源地址**：`https://data.haiwai.ltd`
   - **API Key**：`(管理员单独发给你，不要转发)`
3. 点 **「测试连接」**，出现绿色 ✓ 即通；再点「保存设置」。
4. 此后资讯页/图文页即有数据，无需本机再装任何数据站。

## 二、直接调 API（程序接入）

所有请求带 `Authorization: Bearer <你的Key>`：

```bash
curl -s 'https://data.haiwai.ltd/v1/items?limit=5' \
  -H 'Authorization: Bearer <你的Key>'
```

| 端点 | 作用 |
|---|---|
| `GET /v1/items?limit=&cursor=&source=&market=` | 资讯条目（含标签/市场/行业/事件） |
| `GET /v1/sources` | 可用来源清单 |
| `GET /v1/snapshot/latest` | 最新快照 |
| `GET /v1/status` | 采集状态（哪些源活着） |
| `GET /v1/health` | 探活 |

- 数据每 **15 分钟**自动刷新一轮
- 忘带 Key 或 Key 错 → `401 unauthorized`
- 超过配额（默认 60 次/分钟、20 万条/天）→ `429`，等一分钟再试

## 三、常见问题

- **页面空白** → 先看是不是 429（配额用尽），再看 Key 是否贴对
- **证书警告** → 正常情况不会出现；出现说明你访问的地址拼错了，正确地址只有 `https://data.haiwai.ltd`
- **Key 泄露/离职交接** → 找管理员作废重发，一分钟的事
