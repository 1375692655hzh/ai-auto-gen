# 数据站接入指南（同事版）

> 数据站 = 7×24 自动采集全球财经资讯的中心服务，你只需要一个地址和一把 Key。

## 一、工作台接入（推荐方式）

如果你用的是工作台（图文/资讯页面）：

1. 打开工作台 → **设置页** → **信息源连接**
2. 连接模式选 **「云端数据站」**，填两格：
   - **数据源地址**：`https://data.haiwai.ltd`
   - **API Key**：`(管理员单独发给你，不要转发)`
3. 点 **「测试连接」**，出现绿色 ✓ 即通；再点「保存设置」。
4. 此后资讯页/图文页即有数据，无需本机再装任何数据站。

## 二、直接调 API（程序接入）

所有请求带 `Authorization: Bearer <你的Key>`：

```bash
curl -s 'https://data.haiwai.ltd/v1/items?limit=5' \
  -H 'Authorization: Bearer <你的Key>'
```

| 端点 | 作用 |
|---|---|
| `GET /v1/items?limit=&cursor=&sources=&markets=&forms=&q=&since=` | 条目查询（含标签/市场/行业/事件，`text` 字段即正文全文） |
| `GET /v1/sources` | 可用来源清单（含市场/定位/形态标签与健康状态） |
| `GET /v1/snapshot/latest` | 最新快照 |
| `GET /v1/status` | 采集状态（哪些源活着） |
| `GET /v1/health` | 探活 |

- 数据每 **15 分钟**自动刷新一轮
- 忘带 Key 或 Key 错 → `401 unauthorized`
- 超过配额（默认 60 次/分钟、20 万条/天）→ `429`，等一分钟再试
- **返回里的 `total` 是本页条数**（等于 limit），不是匹配总数；翻完 `next_cursor` 为空才算取尽，别用 `total` 判断有没有数据

### 内容四分类（`forms=` 参数）

条目带「内容类型」标签，四类直取，可与 `markets`/`q`/`since` 任意组合：

| 类型 | 取法 | 是什么 |
|---|---|---|
| 周期报告 | `forms=周期报告` | 每天固定出刊的栏目：富途五栏目（一周前瞻/早报/午评/收评/盘前/收盘）、财联社三早报（有声/港股/科创板）、见闻早餐、日韩/土耳其早报、开市综述等。**全文** |
| 精品文章 | `forms=精品文章` | 深加工分析文：财联社热门榜、华尔街见闻最热榜、长桥海豚投研。**全文** |
| 资讯 | `forms=资讯` | 滚动新闻：智通财经美股（全文）、长桥资讯（全文）、金十·市场参考、老虎/富途资讯流（摘要） |
| 大V文 | `forms=大V文` | 长桥社区大V帖子**全文**（运营帖已滤）；X 平台大V观点另走 `sources=twitter_kol_views` |

```bash
# 例：今天的全部周期报告全文
curl -s 'https://data.haiwai.ltd/v1/items?forms=周期报告&since=2026-10-15&limit=20' \
  -H 'Authorization: Bearer <你的Key>'

# 例：美股精品文章
curl -s 'https://data.haiwai.ltd/v1/items?forms=精品文章&markets=美国&limit=10' \
  -H 'Authorization: Bearer <你的Key>'
```

## 三、常见问题

- **页面空白** → 先看是不是 429（配额用尽），再看 Key 是否贴对
- **证书警告** → 正常情况不会出现；出现说明你访问的地址拼错了，正确地址只有 `https://data.haiwai.ltd`
- **Key 泄露/离职交接** → 找管理员作废重发，一分钟的事
