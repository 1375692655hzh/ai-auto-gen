# 早报自动化运行时间（定案）

> 2026-08-29 调查定案：**周一至周五 08:30（北京时间）启动全链路**，约 08:45 出品。

## 决策依据（实测数据）

### 四个信息源的发布时间

| 源 | 发布时间 | 依据 |
|---|---|---|
| 财联社有声早报 | ~07:00 | 8-28 实测 07:00（7 点档为该栏目惯例） |
| 华尔街见闻早餐 | ~07:02 | 8-28 实测 07:02 |
| **富途早报（港美早报）** | **08:20-08:26** | 三日实测（08:20 / 08:21 / 08:26），最晚且最稳的约束源——等美股凌晨收盘后成稿 |
| Gangtise 投研日报(元宝镜像) | 日期粒度 | 全天研报纪要汇总，无时刻约束 |

**最晚源是富途 08:26 → 启动时间必须 ≥08:30** 才能四源齐抓。

### 日韩行情的设计意图

日韩股市**北京时间 08:00 开盘**（东京/首尔当地 09:00，UTC+9）。08:30 跑批时日韩已开盘
半小时——**这不是冲突，是特性**：早报呈现的日经/KOSPI 涨跌是「隔夜消息后日韩今晨开盘方向」，
为 9:30 的 A 股开盘提供先行参考；A股/美股则如实标「昨收」。组标签在抓取时刻动态判定
（`flows/steps/image.py::_fetch_indices`），随 payload 固化，复跑历史日期不漂移。

08:30 时间点同时满足：富途（最晚源）已发、日韩已开盘半小时（方向稳定）、A股未开盘、
美股已收盘——四类行情各得其所。

### 其他约束核对

- A股开盘 09:30（集合竞价 09:15）：08:30 跑无冲突
- 美股收盘 北京 04:00（夏令时）/05:00（冬令时）：08:30 时已收盘 ✓
- 全链路耗时实测 ~12-15 分钟（fetch 3min + 素材 2min + 文章 3min + tag[K3] 1min + 长图 5min）→ 08:45 前出品，赶上 09:00 前的通勤阅读窗口
- 节假日自护：四源休市日不发早报，fetch 步当日校验（发布日期≠当天）会安全空退，无需单独排节假日日历

## 落地方式

Windows 任务计划程序（同事部署通用）：

```bat
schtasks /create /tn "morning-digest" /tr "py -3.11 E:\ai-gen-article-publish\cli.py flows run morning-digest --set with_image=true" /sc weekly /d MON,TUE,WED,THU,FRI /st 08:30
```

或 Linux cron：`30 8 * * 1-5 cd <项目目录> && python cli.py flows run morning-digest --set with_image=true`

产出在 `autopub/articles/`（文章，进待发队列）与 `autopub/images/`（长图）；
发布一律需人工过 `--draft` 确认，定时任务不做自动发布。

## 行情数据源

- 主源：新浪 `hq.sinajs.cn` 免费指数接口（无鉴权，8 指数一次请求；
  A股 `s_` 系列、美股/日经 `int_` 系列、KOSPI 用冷门代码 `znb_KOSPI`）
- 失败行为：行情区静默跳过，不阻断长图生成
- 备选（未接）：腾讯 `qt.gtimg.cn` 指数接口，主源限流/下线时替换
