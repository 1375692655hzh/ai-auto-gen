# 早报条目「解读标签」设计方案（五方汇总裁决稿）

> codex（工程落地）+ grok（合规/质检）+ gemini-opus（词表体系/结构化）+ kimi（读者体验）四方独立设计，ZCode 汇总裁决。2026-08-28。**待用户批准后实施。**

## 一、需求回顾

每条信息下方追加解读：涉及板块（如英伟达→【芯片】【AI】）+ 每板块影响方向，多/空/中性按方向分行。

## 二、核心裁决（四方融合后的定案建议）

### 1. 生成机制：独立第三步 `tag`，LLM 出 JSON、代码渲染插行（codex 方案，四方实质共识）

```
fetch → synth(素材) → article(文章定型) → tag(解读标签) ← review 审核点移到这步
```

- LLM **永远不碰文章正文**：只输出 `{"n": 条目编号, "dirs": [{方向: [板块...]}]}` 结构化 JSON；解析、校验、插行全部由确定性代码完成——排版正确性是构造性保证，LLM 破坏不了格式。
- 双输入：成品文章（定条目锚点与编号）+ 素材底稿（补判定语境，成品里被删的分析师归因在素材里）。
- 产物双份：带解读版文章进待发队列；`tag-<date>.json` 结构化侧车（gemini 设计，direction 用英文枚举，供未来视频/图片形式直接消费"今日板块热度"）。
- 可降级：JSON 校验失败重试一次，仍失败告警跳过、发无解读版；`--set tag_lines=false` 一键关闭。

### 2. 方向措辞（**需要你拍板的第一决策**）

| 选项 | 示例 | 合规评估（grok 联网核证监管与五平台规则） |
|---|---|---|
| A. 利好/利空/中性（**推荐**） | `↳ 利好：芯片、AI` | 财联社/见闻/证券时报早报通行体例，属"新闻影响归类"；监管三要件（资质/辅助决策/有偿）全不沾 |
| B. 多/空/中性（你的原话） | `↳ 多：芯片、AI` | 交易指令色彩最强，主流媒体早报无一使用；富途/长桥社区规则明确打击"批量买卖消息"，视频号公约把"模板化方向清单"列入黑名单——账号降流风险显著升高 |
| C. 偏多/偏空/中性 | `↳ 偏多：芯片` | 折中，仍属方向判断词 |

**无论选哪个**，配套合规措施：① 免责声明升级为"板块影响标注仅为对消息面的客观归类，不代表走势预测，不构成投资建议"；② 解读行内**禁止出现个股名/代码**（与文末股票 chip 保持隔离，避免"看多板块+点名标的"的荐股结构）；③ 文首可加一行说明（东财/雪球变体启用）。

### 3. 排版格式（kimi 实测 flatten 衰减后定案）

```
- **公司**：英伟达单日市值暴增4420亿美元，股价收涨8.7%……
  ↳ 利好：芯片、AI
- **地缘**：特朗普签署行政令禁止部分外国电力设备进入美国电网……
  ↳ 利空：电力设备
  ↳ 利好：国产替代（此类多空并存才折行）
```

- 行首锚点 `↳`（两个空格+↳）：缩进在发布管线会被剥（实测 content.py parse_markdown），靠符号本身表从属；↳ 在满屏 `-`/`•` 中是唯一异形锚点，读者竖扫即知"这是编辑注不是新闻"。
- **有内容的方向才成行，空方向不占位**（你说的"多一行空一行中性一行"本意如此；72 条×3 行的占位制会把文章撑爆）。
- 同方向多板块一行顿号连接；每条最多 3 个板块、3 行解读；解读行永不加粗（必须比正文轻）。
- 【】不用于板块词（微博端与节标题【】撞形），裸词+顿号。

### 4. 哪些条目加、哪些不加（四方规则表融合定案）

| 条目标签 | 政策 | 理由 |
|---|---|---|
| **概念** | 必加，价值最高 | 散户不知道"超节点"关联什么，解读行为此而生 |
| **政策** | 加；纯表态/远期规划→中性或"关注" | 有实质方向性（扶持/限制/处罚）才给方向 |
| **注意** | 加，天然利空/承压 | 该标签本身就是负面信号 |
| **公司**（事件类） | 加（并购/指引/订单/产品） | 映射+方向都有价值 |
| **公司**（业绩公告类） | 轻标：板块映射+默认中性 | "增长≠超预期"陷阱（grok）；业绩是过去时已 price in，硬标利好=变相荐股（kimi）。素材有"超预期"等显式信号才给方向 |
| **公司公告区**（27 条） | 区末一行热度汇总 + 仅量级异常条（+4925%/扭亏）轻标 | 全标 27 行是灾难，全不标弃守（kimi 折中方案） |
| **数据** | 点名行业且量级异常才加（集成电路利润 18.5 倍→芯片）；宏观总量不加或中性 | "18.5 倍砸在谁头上"是散户盲区 |
| **地缘** | 只标板块映射，方向降格为"承压/扰动/关注"（不给多空） | 多空高度交织硬标是编造（grok）；但"关税影响谁"的映射必要（kimi）——两者融合 |
| **事件** | 有实质影响才标方向；纯会议/揭牌→"关注：主题" | 中性事件不硬凑方向 |
| **行情** | **不加**（四方一致） | 涨跌已明示，再标方向=零信息+预测次日（撞红线） |
| 传闻条（据报/被曝） | 免标 | 方向不能建立在未证实信息上 |
| **今日焦点** | 去重规则：正文有对应条目只标正文处；焦点独有条照加 | 全天最重要的条目恰恰最需要解读（实测今天焦点 3 条中 2 条正文无重复） |

密度预算：强解读约 25-30 条 + 公告汇总 1-3 行 + 公告轻标 3-5 条 ≈ **全文解读 ≤35 行**（72 条文章从 96 行→约 130 行，可控）。

### 5. 板块词表（首版约 30 个，封闭单一来源+人工演进）

合并 gemini（22 题材+分级）与 codex（宽基/商品类）：

- **科技**：芯片、AI、算力、光模块、存储、PCB、消费电子、软件、信创
- **新能源/制造**：光伏、储能、锂电、新能源车、电力设备、电网、机器人、军工、汽车
- **消费/医药**：白酒、食品饮料、医药、旅游、家电、农业
- **金融地产**：券商、银行、保险、地产
- **周期/商品**：黄金、有色、原油、煤炭、钢铁、化工
- **市场类**：A股、港股、美股、中概股

命名铁律（kimi）：用行情软件板块简称（芯片>半导体>集成电路）；同一板块全天只用一个词；新产业链词（超节点/覆铜板）靠解读行完成翻译。
演进机制（gemini 简化版）：LLM 想用表外词→强制回退最近义词 + 记入候选清单，周审人工决定入表。词表放独立配置文件（你可直接改，L1 级自定义）。

### 6. 方向判定纪律（写进提示词，grok L1/L2/L3 分层）

- **L1 素材显式**：素材含"利好/大涨/涨价/超预期/处罚/中标"或机构点评 → 可标
- **L2 数字强蕴含**：业绩/订单数字方向明确 → 可标（只复述数字，禁补原因）
- **L3 多步推理禁止**："美联储鹰派→成长股承压"这类传导推论一律不标
- 上下游反向陷阱：方向是"对所标注的那个板块"而言（铜价涨：矿业利好/线缆利空，分行各自成立）
- 无把握一律中性或跳过，宁缺毋滥

### 7. 机检（并入现有 _lint 管线，违规阻断）

fail 项：板块∈词表逐字命中｜方向∈枚举｜每条≤3 板块≤3 行｜行紧跟所属条目不悬空｜行情/地缘多空/传闻条出现方向即拦（地缘允许承压/关注降格词）｜解读行禁个股名与代码｜解读行禁词（买入/卖出/建仓/抄底/目标价等）
告警项：单方向占比>80%（判定失真，强制走人工审核点）｜中性+免标<20%（全篇方向化="每日喊单清单"形态）
