# 评论生成·人设功能优化方案（grok-4.6 评审，2026-09-09）

> 来源：grok -p 评审 `workbench/server/x_reply.py`（实读代码，工程结论已核对：`_cache_key`=正文|base_url|model|extra_body|PROMPT_V、单次 `_llm` max_tokens=900、TTL 48h，全部属实）。
> 用户目标：账号=金融投资大V，评论生成的目的是给账号涨曝光涨粉。

## 核心诊断

现提示词把「不像垃圾」做对了，但**优化目标写错了**：它在训练「聪明回复机器人」，不是「点进主页后还能认出来的金融大V」。三风格都在服务帖内热评，几乎不服务主页转化。人设功能要补后半段。

转化漏斗：**热评（算法）→ 点头像（读者）→ 点进主页并关注（人设闭合）**

## 1. 什么评论最能涨粉

### 算法侧（X 回复排序权重，硬→软）
1. **作者回评/作者点赞**（最高权重）→ hook 必须让作者觉得「值得当众答」
2. 楼中楼继续聊 → 评论留可接的缺口，别把话说死
3. 账号声誉（人设解决不了，模板指纹会反向摧毁）
4. 停留与「显示更多」→ **首行必须独立成立**（移动端首屏约2行）
5. 他人点赞/回复；负权重：链接/@/求关/复读/早到自夸/跨帖同开头

结论：作者回评是单条评论最大算法杠杆；长评本身不是杠杆，**信息密度+首行可见性**才是。

### 读者侧（什么让人点进主页）
1. 「这人看问题的角度我主页没有」（增量真补机制）
2. 「这人有稳定世界观，不是这条运气好」（同一套判断程序：概率/证伪/仓位/流动性/政策传导）
3. 「主页大概有更完整的跟踪」（好奇心残留，不是 CTA）

涨粉效率排序：①证伪条件型 ②机制补全型 ③作者可答的具体缺口 ④带记忆点的冷判断 ⑤meme同频短刺（只保人味不涨粉）。
伤账号：正确的废话/粉丝口吻/教师口吻/喊单目标价/每条同一开场白。

**人设=可复用的判断程序**，不是自我介绍。评论只留程序一小截，转化发生在主页。

## 2. 铁律取舍

**让路（改不删）：**
- 铁律2「1-3句」→ 改「首行约80计权内独立成立 + 1-4句 + 目标≤240」（金融专业感需半句机制，过短=水军）
- 铁律5锚点保留并收紧：判断程序可重复，开场词/口头禅/框架名禁止跨条重复
- 角色句「评论区抢位写手」→「金融投资大V的评论执笔」

**不让路：** 1跟语种、3禁链/@/求关/硬广、4禁编造、6禁时间戳、7meme/站队。

**新增铁律 8-12：**
- 8 人设一致性：同场交易者口吻（非粉丝/老师/客服），口语：术语≈7:3，条件句概率词，禁「作为一名…投资者」自我介绍，口头禅三条合计≤1次
- 9 合规：禁买卖指令/目标价/仓位配比/保证收益/跟单/内幕暗示；表态只用「我的基准情形是…但若X出现就失效」
- 10 引流唯一姿势=好奇心残留（抛在盯的变量/证伪点/口径差），禁一切显式CTA（含「我主页拆过」「关注我拿框架」）
- 11 互动策略：hook问作者才能答的缺口（口径/样本期/是否含某变量），称呼用「这口径/这个数字」不用「您/老师」；insight补一环不判作者错；contrarian跟情绪保持距离不人身抬杠
- 12 首行即人设：记忆点放第1-2句，不埋折叠后

## 3. 工程与提示词设计

- **人设数据**：预设卡{id,label,one_liner,lens,voice,do,dont} + 自定义textarea（200字硬顶，覆盖one_liner与do/dont）。渲染进prompt ≤180汉字甜区、硬顶240（再长Flash会忽略原帖锚点开始自我介绍）。
- **6预设**：宏观流动性macro_flow / **证伪交易员falsify(默认)** / 定价机制micro_mech / 赔率视角odds / 风险官risk_first / 自填custom
- **拼user不拼system**：system放铁律（稳定约束层），人设是实例变量放user（`[人设 — 只约束口吻与判断程序，禁止把这段自我介绍写进评论]` 包裹防注入）
- **单发不多轮**：人设不改变单次_llm拓扑
- **缓存必改**：PROMPT_V→v2；_cache_key 追加 persona_id+sha1(persona_render)；人设落 settings.json `x_reply.persona={id,custom}`（工作台唯一写口）；端点只传persona不传原帖正文（反注入边界不破）
- **falsify默认渲染示例**：
  ```
  定位: 金融投资大V · 证伪交易员
  一句话: 先写这判断在什么条件下作废，再谈弹性
  判断程序: 失效点 / 反向催化 / 口径是否可比
  口吻: 冷静、短句、同场；不冷嘲作者
  本条要做: 用原帖锚点给出一个可观察的证伪条件
  本条不做: 喊单、目标价、保证、自我介绍、求关注
  补充: 无
  ```

## 4. 三风格够不够？

**P0不加第四条**。人设是三条的约束层不是第四种文体；「亮观点」做成独立风格会产出自我介绍+签名句，正好撞铁律3/5/10。
改造=改写三条成功标准：A hook先亮半句判断程序再问（空问作废）；B insight增量像主页目录一条；C contrarian是人设记忆点主场（冷判断+可记住的失效条件）。
P1实验位：可选第4候选`signature`（基准情形缩微版，UI开关默认关），观察2周C仍抬杠再开。

## 5. _validate 增软规则（记notes不丢弃）

显式CTA词（关注/主页/私信/follow）、自我介绍前缀（作为一名/I am a）、三条开头8字重复。硬丢弃保持链/@/超长/过短。
