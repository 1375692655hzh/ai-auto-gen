# 第四板块【前端工作台 workbench】定稿方案

> 2026-09-03 由 MoA（cursor+codex+gemini+kimi 同题并行）四份方案汇总裁决而成。
> 四份原始答卷存档：`docs/workbench-moa/01-cursor.md`、`02-codex.md`、`03-gemini.md`、`04-kimi.md`。
> 本期交付目标：**5 页 UI 壳 + 展示设计完整落地；资讯页/设置页接真实数据；生成/发布/云端全部留桩。**

## 1. 四家共识（直接采纳）

1. 技术栈：**FastAPI 后端 + 免构建前端 SPA**，否决 React/Vite 工程化——"用户下载即用、纯本地"是硬约束，不能再引入第二条 Node 构建链。fastapi+uvicorn 已是项目依赖（doctor 体检项），零新增依赖。
2. 顶层新增 `workbench/` 与三板块平级，`python cli.py workbench serve` 挂进 cli.py 第四命令组，挂板模式照抄 sources/flows。
3. 资讯页本期就接真实只读数据（sources serve 全 GET 零写，展示真实数据零风险）；写操作（生成/发布/云同步）全部留桩。
4. 发布红线 UI 化：发布类按钮一律 disabled + 提示 `--draft` 先行；账本 `state.json` 永远只读。
5. 云端演进 = 配置切换：数据源抽象为 `{mode, base_url, api_key}`，上云零改前端。

## 4. 后端 API 契约（本期实现）

| 端点 | 说明 | 写? |
|---|---|---|
| `GET /wb-api/health` | 工作台自检 + 代理数据源 `/v1/health` 合并（顶栏健康灯） | 否 |
| `GET /wb-api/v1/{path}` | 透明代理到设置里的数据源（sources serve `/v1/*`），注入 Key，翻译 401/429/连不上 | 否 |
| `GET/PUT /wb-api/settings` | 读/写 `data/workbench/settings.json`（唯一写口；api_key 永不明文回显） | 是（本板块自有） |
| `GET /wb-api/selfcheck` | 三板块关键路径存在性自检（队列篇数/账本条数/flows 数/视频项目数） | 否 |
| `GET /wb-api/flows` | flows 包清单（名称/标题/lint） | 否 |
| `GET /wb-api/runs` | `data/runs/<流>/<日期>/run.json` 摘要清单（状态机回显） | 否 |
| `GET /wb-api/artifacts` | 生成产物（generator/output 的 md/png/daily JSON）+ 待发队列 | 否 |
| `GET /wb-api/ledger` | 发布账本只读视图（published/failed/uncertain 分平台） | 否（红线） |
| `GET /wb-api/videos`、`GET /wb-api/videos/{id}/file/{name}` | 视频项目清单 + mp4/cover 静态回源 | 否 |
| `GET/POST /wb-api/track/accounts`、`DELETE /wb-api/track/accounts/{i}` | 追踪账号清单（落盘 data/workbench/tracked_accounts.json） | 是（本板块自有） |
| `POST /wb-api/cloud/{action}` | 云端登录/同步预留桩 | 501 |

settings.json 形状（本期即定型，上云零改前端）：

```json
{
  "source": {"mode": "local", "base_url": "http://127.0.0.1:8787", "api_key": "", "timeout_s": 15},
  "ui":     {"theme": "dark", "page_size": 100, "remember_filters": true},
  "cloud":  {"endpoint": "", "account": "", "sync_token": "", "sync_enabled": false, "last_synced_at": null}
}
```

`source.mode`：`local`（本机）/ `lan`（局域网数据站）/ `cloud`（预留灰显）。mode=cloud 时 proxy 转发目标换 `cloud.endpoint`——云端化只是 proxy 多一个分支。

## 5. 五页 UI 设计（定稿）

全局壳：左侧固定导航（Logo + 资讯/图文/视频/追踪/设置 + 底部数据源健康灯，30s 轮询）；顶栏当前页标题；主区最大 1200px。设计语言：金融终端风，高信息密度、暗色默认、情绪色（利好绿/利空红/中性灰）。

1. **资讯页**（本期全功能）：左栏标签筛选器（市场/类型/形态/渠道/情绪/事件/来源，选项来自 `/v1/sources` 聚合，组内 OR 组间 AND，已选 chip 可单删/清空）；中栏信息流（搜索 q 中英同检、时效 1h/4h/今日/3天/全部、dedup/display 开关、条目卡片=时间+来源+徽章+正文+tickers+外链+dup_count 簇角标+"加入素材篮"，游标式"加载更多"）；右栏状态面板（命中数、库统计、最近刷新、dead 源清单）。条目卡片"查看原文"展开 text_src。
2. **图文页**（只读+桩）：左=素材篮（资讯页加入，localStorage 暂存，可移除/清空）；中=工作流区（flows 清单选择、run.json 状态机步进回显 done/waiting_review、"开始生成"桩按钮显示对应 CLI 命令）；右=产物预览（generator/output 的 md 渲染/长图/daily JSON 列表）+ 待发队列 + "推入队列/发布"桩按钮（disabled + `--draft` 红线提示）。
3. **视频页**（只读+桩）：左=视频项目卡列表（project.json 门禁 draft→reviewed→built 着色徽章、封面缩略图）；右=详情（story 摘要、`<video>` 播放 out/*.mp4、"构建/投稿"桩按钮附 `video build`/`publish run-video --draft` 命令提示）。
4. **追踪页**（账号真实增删+指标桩）：顶部沙盒提示条；账号卡片网格（平台/账号名/备注/添加时间，增删落盘）；指标区=占位折线 + "采集器将在后续版本接入"文案；底部"已发布内容清单"（读账本 url/platform/time，真实数据）。
5. **设置页**（本期核心写页）：①信息源连接（mode 三选 cloud 灰显 / base_url / api_key 打码 / "测试连接"实时打 `/v1/health` 显示库统计与快照时间 / 保存写盘即生效）；②界面偏好（主题/每页条数/筛选记忆）；③环境自检（三板块路径卡片化）；④账号与云同步（登录表单灰显 + 501 桩接口说明 + 同步范畴勾选预留，API Key 永不同步）。

## 6. cli.py 挂载与 doctor 扩展（定稿）

| 命令 | 作用 | 副作用 |
|---|---|---|
| `python cli.py workbench serve [--bind/--port 8788/--open]` | 启动工作台（静态托管 + /wb-api） | 常驻进程；--open 自动开浏览器 |
| `python cli.py workbench status [--json]` | 工作台/数据源双探活 + 设置有效性 | 无 |

doctor 新增 2 项 warn 级检查：`workbench 静态资源完整`（index.html + vendor/vue 存在）、`供数服务 8787 可达`（不可达时提示另开终端 `python cli.py sources serve`）。

## 7. 红线继承（写进代码结构而非约定）

- views.py 对三板块**全部只读**；state.json/run.json 只读；唯一写口 = data/workbench/ 自己两个 JSON。
- 前端永不直连 8787（代理单点收口）；API Key 不出后端进程。
- 发布/生成按钮本期全部为桩；未来实装时后端只经 subprocess 调 `python cli.py ...`，不 import 三板块内部模块驱动物理操作。
- 默认绑 127.0.0.1；--bind 对外时复用供数服务同一告诫（内网/隧道，禁裸公网）。
