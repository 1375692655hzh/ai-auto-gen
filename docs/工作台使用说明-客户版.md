# 财经工作台 · 使用说明（详细版）

双击 `bin\workbench-open.cmd`，程序会自动启动服务并打开浏览器（`http://127.0.0.1:8788`）。顶部导航共 5 个大页，**每个页面左侧都有子页菜单**——先选功能，再在右侧操作。各类 API Key 只需在「设置」页填一次，全程浏览器操作，无需命令行。

## 一、资讯 —— 全球财经快讯

**信息筛选**：滚动阅读全球财经快讯流，覆盖宏观数据（CPI、非农、GDP）、央行动态、个股公告、市场异动等。顶部筛选条支持按市场（美国/中国/欧洲/加密等）、板块、信息类型、情感、股票代码组合过滤，支持关键词搜索；筛选可以记住，下次打开还在。

**自动翻译**：看不懂的外文内容不用任何操作——**页面滚到哪，可视区域内的条目自动翻译成中文**，已看过的内容有缓存不重复消耗。翻译 出厂带免费模型链，也可在设置里换成自己的付费 Key。

**素材池**：看到有价值的内容，点条目上的「+」收入素材池（顶部篮子），可继续逛不跳页。素材池是「图文 → 内容生成」的原料仓，支持搜索和手动录入自己的素材（如群聊消息、研报片段）。

**来源详情**：全部数据来源的名录卡片——每个源的定位简介、覆盖市场、健康状态（正常/熔断）、上轮刷新耗时。不想看某个源？关掉侧面的开关，它就从你的资讯流和统计里消失——**只影响你自己的视图**，不影响数据采集，随时开回。可给常用源点星关注，快人一步过滤。

## 二、图文 —— X（推特）内容的看、蹭、写

**推荐信息**：从数百个财经大V账号的实时内容里，按互动数据与金融价值评分（P0~P3 四档）排序，挑出当下最值得看的帖子。支持按市场/板块过滤，每条标注价值分与依据，滚到哪翻译到哪。

**蹭蹭流量**：X 上的实时热帖榜，按爆火概率/浏览量/评论曝光排序。对每条热帖可点「写评论」——AI 按你选择的人设（宏观流动性、证伪交易员、定价机制等内置人设，也可自定义 200 字人设描述）自动写出多条候选评论，挑一条顺眼的复制去回复，蹭热点引流。

**内容生成**（核心功能）：左侧勾选素材池内容，右侧排列生成模块——「信息检索」（按标的回查背景）、「快照抓取」（自动生成近 3 个月 K 线配图）、「技术分析」（支撑/阻力位叠加画图）、「聚合分析」（汇总大V与机构观点）。然后选语种（英/简中/繁中/日/粤）、字数档（免费档约 140 汉字推文 / 付费档最长 2.5 万字符长文）和信息结构模板（事件快评、业绩拆解、数据读数、政策纪要、盘面综述、深度观点、风险提示、串推等 13 张，支持自建模板）。点生成后实时显示进度，成稿可继续编辑、直接进发布流程。

**账号管理**：X 池全部账号的名片墙，支持搜索。每个账号可独立设置「看与不看」——停用后推荐信息、蹭蹭流量、热点采集三处同步隐藏该账号内容。

**内容发布 / 自动化任务**：生成的稿件先进草稿箱，确认后入待发队列（发布需要额外开通发布模块）；自动化任务支持定时生成、定时入队列的计划配置。

## 三、视频 —— YouTube 热点与视频生产

**热点追踪**：YouTube 财经频道最新视频榜，按频道分组、按时间或播放量排序，发现好素材一键加入视频分析库。

**视频分析**：让 AI「看片」——支持 YouTube 链接和本地上传的文件。自动产出：完整字幕、内容摘要、分章节要点、可引用的素材卡片。另支持 copylab 路线：提取文案框架并**逐条机器核对引用真实性**，出核验通过率报告。

**视频制作**：从稿件到成片的完整流水线，分五步走：① 建项目 → ② 写口播稿（AI 生成或粘贴，多种结构模板）→ ③ 生成分镜脚本 → ④ 配音（多音色 TTS）→ ⑤ 渲染出片（横版 Story / 竖版 Short 自动适配）。两条路线任选：**文案路线**全 AI 生成；**音频路线**上传你自己的录音（mp3/wav 甚至视频抽音轨），AI 转写对齐后按你的原声剪片，适合真人出镜口播的账号。

**模板仓库 / 素材仓库**：视频项目的可复用脚本骨架与素材资产管理，好用的结构存成模板，下个视频直接复用。

## 四、追踪 —— 自选账号的数据面板

追踪的账号完全由你自己添加——**适合盯自己的账号表现**，也适合观察同行。

**X 账号**：每账号追踪粉丝数、今日增粉、今日更新数、内容互动量四项核心指标，每日自动快照；点账号行展开曲线图，时间范围 7 天/30 天/90 天/一年/全部自由切换，增粉红绿一目了然。工具栏直接输入 @handle 添加，同模块一键统一采集。

**YouTube**：与 X 同标准的六项指标——粉丝数、今日增粉、今日更新、最新视频流量、近 7 日视频总流量及其变化，同样行内展开曲线、支持长期记录（数据保留一年以上，可看全年趋势）。

**发布与通讯录**：已发布内容的历史账本与平台账号通讯录，发了什么、什么时候发的、效果如何，一页看全。

## 五、设置 —— 一次性配置（最重要）

分七区卡片，**新用户只需关心前四个**：

1. **信息源连接**：填数据站地址与 API Key（开通时提供），保存后资讯页即刻有数据。本机部署默认自动连接，无需改动。
2. **成稿模型**：填你的 AI 供应商地址、Key、模型名（如智谱/DeepSeek/火山方舟），点「测试连接」变绿即成。支持配置**多条模型按优先级自动兜底**——某家故障或欠费时自动切换下一家，生成不中断。
3. **翻译模型**：推荐免费方案，设置页有完整引导（含各方案的网络要求说明），照着一步步来即可；也可直接填自己的 DeepSeek 等 Key。
4. **界面偏好**：深色/浅色主题、每页条数、筛选记忆开关。
5. 其余分区（行情源、TTS 音色、系统状态）均有默认值，不动也能正常用。

每个 Key 卡位都有「测试连接」按钮，**填完先测试再使用**是唯一建议的操作顺序。所有 Key 只存本机服务器文件，界面只显示尾四位。

## 每天 30 秒

刷资讯（外文自动翻译）→ 图文页看大V动态 → 有感素材点「+」入池 → 内容生成一键出稿 → 发布队列确认 → 追踪页瞄一眼自己账号数据。

## 常见问题

- **翻译不动了**：屏幕会弹出带「设置 → 翻译模型」链接的提示，点过去按引导配置；多为免费链当期不可用，换推荐方案即可。
- **成稿报"未配置成稿模型"**：到 设置 → 成稿模型 填 Key 并测试连接。已配置过多条时系统会自动换下一家重试，若最终失败通常是所有链位的 Key 或额度问题，逐个「测试连接」定位。
- **某来源持续无数据**：到 资讯 → 来源详情 查看该源健康状态，红色熔断状态会在数据站侧自动恢复，无需操作。
