# 财经工作台 · 使用说明

双击 `bin\workbench-open.cmd` 自动启动并打开页面。顶部 5 个大页，**每页左侧有子菜单**，先选功能再操作。各类 Key 只需在「设置」填一次。

## 资讯

全球财经快讯（宏观、央行、个股、异动）按市场/板块/标的筛选，支持搜索。**外文内容滚到哪自动翻译到哪**。点条目「+」收入素材池，供写稿用。「来源详情」里可关掉不想看的源，只影响你的视图，随时开回。

## 图文

- **推荐信息**：数百个财经大V的实时内容，按互动量和金融价值分级（P0~P3）挑着看。
- **蹭蹭流量**：X 热帖榜，可让 AI 按你的人设一键写蹭流量评论（多候选）。
- **内容生成**（核心）：素材池内容 + 行情/大V观点，一键生成 X 风格帖子——单帖/串推、中英日繁粤多语、多种结构模板，生成后可编辑、配 K 线图、进发布队列。
- **账号管理**：全池账号搜索，每号可设「看与不看」，停用后推荐/蹭蹭/采集三处同步隐藏。

## 视频

- **热点追踪**：YouTube 财经频道最新视频榜，一键加入分析。
- **视频分析**：AI 看片——自动字幕、摘要、分章要点，做二创素材。
- **视频制作**：写脚本 → 自动分镜配音（多音色）→ 渲染横版/竖版成片；也支持上传录音、AI 对齐原声的路线。

## 追踪

自选账号（适合盯自己的号）的数据面板：**X** 看粉丝/今日增粉/更新/互动量曲线；**YouTube** 看粉丝、增粉、更新、最新视频流量、近7日总流量及变化六项，行内展开 7/30/90 天及更长的曲线。同模块一键统一采集。「发布与通讯录」记已发内容和平台账号。

## 设置（最重要，一次性）

新用户只需管前四项：**信息源连接**（填数据站地址和 Key，随开通提供）；**成稿模型**（填你的 AI 供应商地址/Key/模型名，支持多条按优先级自动兜底）；**翻译模型**（有免费方案，照引导来）；**界面偏好**。每个 Key 卡位都有「测试连接」——**填完先测试再使用**。

## 每天 30 秒

刷资讯（自动翻译）→ 看大V动态 → 素材入池 → 一键成稿 → 追踪页瞄一眼自己账号。

## 常见问题

- **翻译不动**：按弹窗里的「设置 → 翻译模型」链接去配置。
- **成稿报未配置**：设置 → 成稿模型填 Key 并测试；已配置过会自动换下一个模型重试，通常是某家 Key 或额度问题。
