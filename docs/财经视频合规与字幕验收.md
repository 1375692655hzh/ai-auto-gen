# 财经视频合规与字幕

finance-video 第三方经验按本仓修正方案吸收；仍按场景整段合成，不逐句调用 TTS。

## 合规与核对

`finance_compliance.py` 提供十二条提示词纪律与司法监管、新股打新、财报产业链三种声明。
NARRATION_SYSTEM 负责口播改写；STORYBOARD_SYSTEM 保留已锁定口播，对违规原句写 warnings，要求返回口播阶段修改。
`wb-video-script/v1` 的 JSON 顶层可选 `disclaimer`，脚本预览显示、脚本存档保留；不修改 Story TypeScript 契约，不宣称渲染已展示该字段。

两条 workbench CLI 构建路径成功后，读取最终落盘 story.json 的 narration，确定性写出 `out/发布前核对.md`。
提取百分比（含中文口播写法）、亿/万/万点、基点与日期；公司名称使用后缀候选，大写 ticker 使用与既有来源去重规则相同的字母范围思路，并兼容 cashtag。
候选可能误检或漏检，尤其中文简称、英文混合大小写品牌以及“三十年”这类期限，文档明确要求人工补齐。窗口建议按关键字匹配，不等于事实核查或自动发布许可。

`views.video_file` 只扩展 `.md` 白名单；产出列表新增 `has_review`，本项目产出卡显示下载链接。
HTTP 仍只读项目目录，核对文档仅由 CLI 写出。

## 字幕来源与限制

已检查本地 `msedge-tts@2.0.7`：`setMetadata` 第三个参数支持 `wordBoundaryEnabled`，`toStream` 返回 `metadataStream`。
事件 `Metadata[].Type=WordBoundary`，时间为 `Data.Offset` / `Data.Duration` 的 100 ns 单位（除以 10,000,000 转秒），文本为 `Data.text.Text`。
该版本结束时关闭 audio，再销毁 metadata，不能等待 metadata 的 end 事件。

共享 synthEdge 出口将原始词界保存为 `<scene>.cues.json`：

```json
{"origin":"provider-alignment","unit":"seconds","narrationHash":"sha1前10位","cues":[{"t":"收入","start":0.1,"end":0.5}]}
```

有效词界优先；按照原稿恢复标点、聚合短句，取首词开始与末词结束。长句仅在真实词边界切分，不对词内时长估分后冒充精确对齐。
旧 `.alignment.json`、显式 scene frame cues 仍兼容。预置语音复制同名词界轨；换音频时清除目标目录过期派生字幕轨，不删除源音频。
缺词界走 `approximate-text-weight`：先句号/问号/感叹号切句分配停顿权重，再按句内字符权重分配时间。
轨损坏、文本不符、哈希不符或时间重叠/越界，回退并写 QA warning。
所有方法写入 timeline.json / verify.json，SRT 和屏幕字幕共用同一时间轴；估算无法反映真实变速或停顿。

2026-09-09 本环境两次 Edge 实测均因 WebSocket `EACCES 198.18.2.255:443` 失败（各重试 8 次），因此支持结论仅到本地 API 和模拟事件验证，尚未完成线上词界验收；需在网络可达环境补跑。不得把本次历史音频样片称为词级精确对齐。

## 场景时长与静帧

场景时长为原时长与 5.5 秒的较大值；新增的尾部由 Remotion Freeze 保持原视觉最后一帧，音频在 Freeze 外播放。
从最终视频按每场累计首帧号导出 `out/keyframes/<scene>.png`，使用 Remotion 自带 FFmpeg 的 `trim=start_frame`（精简版不含 select）。静帧不足写入 QA errors，不标构建成功。
首帧可能仍在入场动画起点；封面另外保留 0.7 秒的稳定画面。

## 验收与隔离

`python scripts/verify_finance_video.py prepare` 创建 `data/tmp/finance-video-acceptance` 隔离样本，随后可执行 `narration`、`voice`、`render`。
`prepare-short` / `render-short` 使用历史短音频单独验证 5.5 秒兜底；不伪造词界。
物理执行始终调用 `python cli.py workbench ... --data-dir <隔离目录>`；参数仅影响当前 CLI，目录须在本仓 data/ 下，不改变 HTTP 服务和用户配置。
测试设置副本可能含凭据，验收后删除整个隔离目录；保留的交付目录只复制成片、报告、字幕、静帧与去密钥证据。
不重启 8788，不提交、推送或发布；上线由主会话重启后端并刷新 SPA。
